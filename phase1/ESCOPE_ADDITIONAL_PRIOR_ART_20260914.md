2026-09-14增补：已核[CodeScaler](https://arxiv.org/html/2602.17684v1)摘要/引言（未阅读全文），其execution-free code reward model与validity shaping意味着“执行前预测程序成功”本身不是新主张。[Calibrate-Then-Act](https://arxiv.org/abs/2602.16699)和[Automata from Agent Traces](https://arxiv.org/abs/2608.23670)仅核摘要，分别涉及环境先验与成本不确定性、由agent轨迹预测失败/提前终止。当前廉价HGB不自称新算法；需要同预算MLE最终质量、强短代码参照、跨生成器迁移及从真实失败数据获得的可重复机制证据。

## 还值得测、但尚未成立的问题

在同一真实预算、同一生成器及搜索规则下，编辑自由度是否产生**可执行探索收益与表示能力损失的取舍**？需分别测交付质量、强传统参照、成功执行进度以及被限制的变换能力。不能把有效执行率当最终成绩，也不能把观测关联叫因果中介。

当前接口并不是只允许已编码数组：`build_model(X)`内仍可更换预处理，Space仍含Cabin等原始类别列。外壳在构造默认X/Z时删掉PassengerId和Name，这只是传参信息差异，**不是原始列绝对不可访问**：原始train/test全局变量与公开数据文件仍在，函数可以访问它们。任意Python函数还可改变全局状态，所以外壳AST相同不保证运行语义、数据使用或验证流程必然相同。干预应称返回代码表面/接口约定变化，不称严格表示能力上界或安全隔离。
