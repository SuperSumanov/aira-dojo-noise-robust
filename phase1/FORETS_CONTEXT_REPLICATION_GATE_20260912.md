# 在seed13揭盲前固定的重复规则

2026-09-12 UTC。13123仍在首个run运行，尚未读取任何seed13最终成绩。
目的：防止只在看到正差值之后才重复，从而把探索波动包装成稳定critic收益。

若seed13四run全部终态、独立检查通过、无未解决的控制器/接口/账本/隔离错误，且至少一个任务两臂都有合法最终提交，
则用完整原两任务×新seed14×原两臂再做4run；不以成绩差的正负或大小作为是否重复的条件。
若没有可比对、出现需修复的执行系统问题或新增不明API责任，则先诊断，不增加同配方GPU作业。
任务程序自身报错/超时不按系统错误重跑，也不删除；缺失final不赋零。

seed14须保持seed13的生成器、完整上下文裁判、双序Borda/top2/common-priority、镜像、资源、程序/搜索预算及留档逻辑。
允许变化只有seed/既定臂序、运行身份和累积费用结转；task source如变化，必须证明只改预算授权常量。
仍是gpu28/单RTX3090/6CPU、4run顺序、280分钟分配，新增最多5GPUh。
每run共同4USD与所有API合计100调用限制不变；Flash预留0.70、Plus2.60USD。

不得与13123并发修改同一账本。父块完全闭合后逐行结转并封存旧scope；旧未知0.70USD始终保留。

这只是冻结后继规则，不代表seed14已经准备好、已经提交或另获一份重置预算。
所有两任务两seed的合法/缺失结果共同报告；即使方向一致，也不能直接称跨任务泛化、机制归因或clean scaling。
