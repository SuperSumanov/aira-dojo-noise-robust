# NeurIPS paper checklist — provisional closure report (2026-09-03)

This report applies the official NeurIPS 2026 sixteen-item paper checklist to the
Decision Corpus draft as a provisional gate for the intended 2027 Evaluations &
Datasets submission. The 2027 call and template are not published, so every answer
must be revalidated when they appear.

## Outcome

- checklist questions present: **16/16**;
- provisional answers: **7 Yes / 5 No / 4 N/A**;
- template TODO answers remaining: **0**;
- prospective label/outcome/prediction/accuracy/utility/identity reads: **0**;
- GPU, paid API, model fit, base-model update: **0 / 0 / 0 / 0**.

The checklist-presence engineering gate is closed, but submission readiness is not.
The No answers are intentional and should not be cosmetically converted to Yes.

## Remaining hard blockers

1. **Main-result reproducibility and open access (items 4--5).** The anonymous
   aggregate preview can regenerate figures and verify aggregate scope, but it lacks
   the content-bearing v11 rebuild and 931-row inputs needed to recompute the historical
   headline table. A reviewer-accessible anonymous host is also absent.
2. **Compute ledger (item 8).** Reported CPU experiments now have concrete worker,
   package, fit, warmup, and query details, but total corpus-production, historical
   model/judge, storage, preliminary, failed, GPU, and API compute are not consolidated.
3. **Existing-asset rights (item 12).** Per-task competition rules, provider-output
   terms, derived-artifact license, LICENSE/NOTICE, and the final license registry remain
   open.
4. **New-asset documentation and hosting (item 13).** Data card and rebuild/audit
   contracts exist, but the final anonymous landing page, content-bearing release,
   Croissant core/RAI record, license, and reviewer bundle do not.
5. **Human author attestation (item 9).** The Code of Ethics answer remains N/A until
   the authors personally review and attest it. The build pipeline must not auto-promote
   this answer.

## What this successor adds

The 2026-09-02 eight-page draft and its receipt remain immutable. A deterministic
successor adds a broader-impact and safeguard discussion, an explicit LLM-use
declaration, and a supplement section with the exact historical predictor settings,
bootstrap units/seeds, and deployment-cost worker protocol. It does not change any
scientific number or unseal any prospective result.
