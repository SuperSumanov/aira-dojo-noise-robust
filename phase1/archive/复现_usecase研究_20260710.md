## 1. H1 — probe 独立于自报分（设障）

```bash
# 正常 + 设障，全 5 臂 × 3 seed × intra/loto，code 4000（probe 从 code 学，长 code 关键）
sbatch --export=ALL,OUT=phase1/_h1u_intra,MODE=intra                 scripts/h1_matrix.sbatch
sbatch --export=ALL,OUT=phase1/_h1uabl_intra,MODE=intra,EXTRA=--ablate scripts/h1_matrix.sbatch
# (loto 同理)
```
`h1_matrix.sbatch` 硬编 `--critics one_epoch,asha,zeroshot,probe,scalar --seeds 0,1,2`（避开 `--export` 逗号 bug）。
**结果**：probe 设障 intra **+0.356** / loto **+0.179**（baseline 崩 0）→ 独立价值成立、robust。

## 2. H2 — reasoning-first vs scalar

```bash
# scalar 与 reasoning 分开跑（避 --export 逗号 bug），都 max_code 1200 保证公平
sbatch --export=ALL,CRIT=scalar,MAXCODE=1200,SEEDS=0,CARDS=phase1/cards_real_mm.jsonl,OUT=phase1/_h2u_s_intra,MODE=intra scripts/reason_fix.sbatch
sbatch --export=ALL,CRIT=reasoning,MAXCODE=1200,SEEDS=0,CARDS=phase1/cards_real_mm.jsonl,OUT=phase1/_h2u_r_intra,MODE=intra scripts/reason_fix.sbatch
```
reasoning 用 **14B teacher**（`reasoning.py` 默认 `teacher_path` 指 14B）。
**结果**：reasoning < scalar（intra −0.146 vs −0.065）；14B teacher 让 spaceship reasoning +0.310 反超 scalar（nuance 保持）。

## 3. budget — rank ≠ regret（best-of-K 省评估证伪）

```bash
sbatch --export=ALL,PYMOD=phase1.budget_probe scripts/probe.sbatch
```
固定预算 K，比 critic(probe) / proxy(自报分) / random 选出的解真 grade。
**结果**：分散任务 tps 上 **proxy regret=0 完胜**，probe ≈ random → probe 不能省评估。

## 4. rescue — 自报分失效检测（换角度，有限成立）

```bash
sbatch --export=ALL,PYMOD=phase1.probe_rescue scripts/probe.sbatch
```
在自报分**排错**的候选对上看 probe 补救率（random=0.50）。
**结果**：spaceship(221) probe@wrong **0.59**（8382 对）→ probe 在自报分失效处仍有独立判断（reward-hacking 检测用途）；有限（部分独立、tps 上失效）。

## 关键坑（本轮踩到 / 沿用）

- **`--export` 逗号 bug**：SLURM `--export` 用逗号分隔 KEY=VAL，值里含逗号（如 `CRIT=scalar,reasoning`）会被拆坏 → 只传第一个。对策：单臂传 `CRIT`，或在 sbatch 里硬编多值。
- **`max_code` 参数化**：`run_full_matrix.py --max_code`（默认 4000）控制 scalar/probe/zeroshot 的 code 字符数；reasoning 内部固定 1200。**H1 用 4000**（probe 从 code 学，短 code 会把设障成绩从 +0.36 压到 +0.02），**H2 用 1200**（reasoning 的 768-token prompt 要塞下指令 + 与 scalar 公平）。
- **prompt 截断 bug**（已修）：code 放 `#Instructions` 前、prompt 被截时指令被挤掉，模型续写代码 → reasoning 曾整段没真跑；`build_value_prompt` code 截到 1200 + dump 诊断。
- 沿用：guard-fix (`interpreters/python.py:189`)、`--exclude=projgpu8`（DeepSeek 抽风节点）、tps MCTS 采树低产（5h 才 ~10 卡）。
