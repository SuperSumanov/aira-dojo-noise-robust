# 预注册 C2:自报分可靠度能否**事前**预测 critic 值不值得训(2026-08-09,开跑前)

## 主张形态(为什么它不需要打赢自报分)

七次尝试证明:学出来的 critic 在任何区域都赢不了免费的自报分。C2 换一个层级发问——
**不问"critic 能不能赢",问"在哪些任务上 critic 有可能赢,而且能否事前廉价判定"**。
如果 ρ(自报分, 真分) 能单调预测 critic 的跨任务准确率,交付物就是一条可执行规则:
**新任务上先花约 20 次评估测 ρ,据此决定要不要训 critic**。这把负面结果转化为决策工具,
且成立与否**不依赖 critic 赢过任何人**。

先导证据:n=5 上 Spearman = +1.000,精确置换 p = 0.0083。n=5 不足以下结论,故扩样。

## 固定设计(结果出来前写死)

**任务集**:`value_pairs_v4.jsonl` 中 ≥2,000 对、且在 v7 语料上有 ≥40 张卡同时具备
自报分与真分的全部任务。按此规则**当前确定为 10 个**:
chaii / petfinder / spooky / birds / nomad / tps-may / tweet / google-quest /
tps-dec / us-patent。名单据规则生成,不得事后增删。

**训练配置**:全部 10 折**同一配置**(老的 5 折训练在 v3 上,训练集不同不可混用,
一律在 v4 上重跑):`--sizes 4000 --max-len 2048 --eval-cap 2000 --eval-stratify
--loto <task> --seed 7`,pairs = value_pairs_v4.jsonl,cards = cards_current_v7.jsonl。

**LOTO 天然免疫 run 泄漏**:整个任务被留出,该任务的任何 run 都不在训练侧。

## 判据

1. **主判据**:Spearman(ρ, LOTO acc) 的精确置换 p **< 0.01**(单侧,方向预先指定为正),
   n ≥ 8 折成功完成。
2. **样本外**:剔除原有 5 个任务后,仅用新增任务重算 Spearman,**方向须仍为正**。
   (不要求单独显著,n 太小;只要求不反向。)
3. **混杂控制(必须报)**:ρ 与 LOTO 可能同被"任务数据多/干净"驱动。报告
   **偏 Spearman**,控制 (a) 该任务的对数、(b) 该任务的卡片数、(c) 该任务真分的方差。
   **偏相关须仍 ≥ +0.5**,否则判为混杂,主张降级为"描述性关联"而非预测规则。
4. **不做的事**:不因结果不好而改任务集、不换统计量、不挑阈值。任一判据不过即写为负面。

## 预先声明的解释边界

即便全过,这条只说明 ρ **预测** critic 表现,不说明 critic 有用。论文里必须与
"critic 在所有区域均被自报分支配"并列陈述——两者合起来才是完整的、诚实的结论:
**critic 的适用性可以事前判定,而在本语料的任何任务上判定结果都是"不值得"。**
