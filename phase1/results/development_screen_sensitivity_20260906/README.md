## 结论及边界

固定四fit screen适合作为**是否值得继续投入的开发筛查**，不能按显著性确认来解释。
在这组指定Gaussian模型中，若训练随机性会同时影响全部任务，增加任务数也不能消掉这部分误差。
例如28任务、全局training-seed标准差2pp的情景，真实平均收益0时，仍有10.173%的模拟通过投资门。
**这不是我们项目的实测误报率或真实功效**；方差、任务数、每任务100对都是事先设定的假设，没有从语料估计。

真正均值恰为+2pp时，对称连续误差下`观测均值>=2pp`的解析概率为1/2；再加同向seed和LOTO门不会提高它。
表中少量50%以上是Monte Carlo误差，不是推翻解析关系。故未通过screen不等于证明方法无收益；
通过也不等于确认成功。真实+4pp情景更容易通过，但不能据此宣传我们已有4pp收益。

既有开发/确认协议、任务、seed、阈值完全未改。不会因本模拟补seed、降低+2pp门、借CI救结论或自动开15-fit。
全部真实开发结果仍应完整报告；正screen只进入原来更严格的确认阶段，混合/低幅度情况仍未判定。
任务bootstrap区间是给定已训练模型的描述性区间，不是对训练随机性的充分不确定性估计。

## 独立核验

核验器不导入模拟器，从协方差之和重算宏平均方差与解析正态点门概率，
以score二次方程独立重算Wilson区间；核全部矩阵、seed、互斥分类计数及全门为点门子集。
最大模拟—解析点门误差0.0021999999999999797；最大两次差0.0030879999999999797；
最大MC区间半宽0.0019599489263972536，均在预先门内。
MC区间衡量模拟数值精度，不衡量Gaussian模型是否符合真实项目。
