# 同一执行记录派生比较：共享噪声的机制边界

2026-09-07；仅合成数学诊断，不是实际 critic 收益、实际标签噪声估计或新算法。
源版本 `01ad9466aa9bffe6b0a220c4e33c191cd6724599`；远端实际 Linux 18 测试通过。
生产 A/B、独立验证 A/B 分别逐字节一致；七个原始产物按 bytes/SHA 导出，见 export_manifest.json。
CSV 的 A/B 是实现复现，不是独立统计样本，不对重复相同矩阵计算置信区间。

固定六节点 path/star，从五条树边扩充到十五条 complete-graph 边；目标仍为原五条树边差。
设 `d = B(theta + eta) + epsilon`，节点噪声方差 rho/2、独立边噪声方差 1-rho，
使每条边的边际噪声方差恒为 1。成对差估计方差为 `(1-rho) R_eff + rho`。
独立实现不调用生产器，直接构造完整边协方差、零和参数空间和 GLS 信息矩阵；
两实现最大绝对差为 `1.3322676295501878e-15`。

这明确了一个解释风险：当比较完全来自同一批带噪执行标量时，增加图中 cycle 不产生新的独立执行观测。
旧有效电阻结果仍是结构/独立边噪声代理；不能直接写成真实 execution-noise 被降低多少。
但这**不证明 G-to-L 无益**：连接原来分离的成分、改变可学习特征约束、优化与局部适配，仍可能有作用。
本诊断也不覆盖二值 Bradley–Terry 或神经网络的泛化误差，不估计真实 rho。
