# TaskBalance v5-r3 monitor-repair deployment

This package records a result-blind deployment receipt. It publishes no candidate, label, prediction, balance value, accuracy, effect, utility, raw archive, or credential.

Two immutable failed attempts are retained remotely. Both stopped before candidate creation and scientific readout. The deployed r3 parser accepts only explicitly named snapshot-identity fields and keeps the original first-successor population and scientific gates unchanged.

The recorded PID and live state are point-in-time observations; the immutable source, failure-file-set, preflight, handoff, and deployment hashes provide the durable provenance.
