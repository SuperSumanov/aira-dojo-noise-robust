# 公开训练规则基线的回顾性检查

正式逐端点数据请使用 `rows-v2.csv` 和 `summary.json`。`rows.csv` 是导出时遇到缺失端点可选字段错误所留下的部分表，仅保留为失败证据，不能拿它算覆盖或均值。`export-review.json` 绑定修正前后的哈希，规则和已计算分数未改变，未重新拟合或评分。

固定9个历史端点中2个缺失；7个有效端点只有6份不同预测，均来自同一任务的两个旧代码起点和同一开发集，不是6个独立任务或独立终评。规则族在观察旧规律后设计，内部公开训练确认不消除这个回顾性限制。零新增GPU的后处理仍继承初始模型成本。

`independent-verification.json` 复核了规则选择、训练和开发输入ID隔离以及全部已有提交；`strong-reference-review.json` 表明人工指导的三个生成seed中位数仍未超过简单基线。当前不据此宣称自动方法已经胜强基线或支持顶会主张。

`harm-plan.json`、`harm-review.json`、`harm-rows.csv` 和 `harm-verification.json` 是后续的逐样本损伤分解。规则、端点和阈值没有改变，仍只使用此前批准且已经评分的开发数据；这不是一次独立重复。六份不同预测虽总分均提高，其中三份含变差的样本；最强原预测改善11行、损伤3行，净增0.0008196438615756983。非目标范围预测逐字不变，不意味着目标范围内无损。这里的 finite_set_worst_incumbent_difference 只是该批数据上相对于目标范围完美预测的算术下界，既非置信下界、泛化保证，也非可部署的oracle。
