## 实际完成

- 固定5个seed、每场景每seed2000次、4个场景。20个独立组各64个二元正确性变化；目标组始终为0。全部合成，0真实任务数据、0模型调用、0GPU/模型fit/候选执行。
- 4种测量规则共80条逐seed CSV；40,000个合成数据重复，不能叫40,000次agent实验。所有规则共享每次的同一数据。
- 脚本计时0.3242358999996213秒（不含解释器启动与输出写入；100个独立warmup draw排除），Python版本及平台在summary.json。
- 10个单元测试通过；精确尾概率另用穷举短硬币序列核验。4个零效应概率与独立整数二项公式一致（事前6倍Monte Carlo标准误容差）；PowerShell独立核80行→16组聚合及源码/协议SHA。
- B/C示例包含逐字相同的全部facts（包括不确定状态和校正统计），只改变使用事实的指令。没有调用LLM，不能判断生成质量或token成本；没有接入生产。

## 数值与代价一起报告

下列百分比是合成重复中的“给出正向证据”频率，不是准确率、MLE提升或真实数据的误报估计。括号内为5个seed之间的标准差，单位百分点。

| 场景与测量规则 | 均值 | 中位数 | seed标准差 |
|---|---:|---:|---:|
| 全零效应：20组事后挑任一、不校正 | 44.84% | 44.75% | 0.71 |
| 全零效应：20组任一、家族校正 | 3.51% | 3.40% | 0.63 |
| 全零效应：只检验事前目标 | 2.77% | 2.85% | 0.38 |
| 全零效应：事前目标也按20项校正 | 0.15% | 0.15% | 0.11 |
| 较弱目标信号：只检验事前目标 | 14.22% | 13.60% | 1.28 |
| 较弱目标信号：目标按20项校正 | 2.02% | 2.15% | 0.33 |

零效应下，前两项的解析概率分别为0.45587586333545005与0.03625999420724524；与模拟差异是采样波动，不将观测44.84%当理论常数。

较弱信号在此指组内改进概率.55、每组仅64个样本；不是对真实MLE效果大小的估计。校正后更少误报也更难检出真信号，故不能将“证据不足”当作候选必然无价值。统计校正和事前目标不是本项目新算法。

另外保留一个反例：事前目标组改进概率.7，其他19组.45，真实整体方向为负。64.60%的合成重复同时出现“目标经家族校正仍有正向证据”和“观测整体退化”。局部正确不代表全局有益；目标解释必须与整体事实一起交付。所有强信号及其余规则结果在summary.json，未删负面或不利结果。

## 对主线的具体影响

1. 目标与分组规则在本次结果出现前确定；不得事后找一个亮点冒充原修改成功。
2. B/C共享所有事实，C不得独占更准确的诊断、更多检查或标签。生产中应使用真实任务metric，不能拿本玩具accuracy检查代替AUC、logloss或Spearman。
3. 不因不显著就拒绝候选；不因局部变好就接受候选。原型只改变反馈，不改变两臂共有的选择/接受/Debug规则。
4. 对已反复查询的D_search，本检查没有全搜索误报保证；必须保留独立终评。实际提升仍需真实生成与执行，不能从本轮结果推导。
