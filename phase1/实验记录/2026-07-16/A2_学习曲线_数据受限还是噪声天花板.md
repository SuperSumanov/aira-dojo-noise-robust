# A2 学习曲线：probe 是"数据受限"还是"撞了噪声天花板"？

**日期：2026-07-16** ｜ 脚本：`phase1/a2_learning_curve.py` ｜ 零 GPU、离线

---

## 一、这个实验在验什么

Stage B 暴露了一个问题：现有数据太少，很多东西离线测不动。那**再堆更多数据到底有没有用**？

做法：对每个任务，固定留一批测试集，用 N 张卡训练 probe，在测试集上测精度，把 N 从小到大扫，多次重采样取平均。
- 若精度在 N 到达上限时**还在升** → **数据受限**（多刷卡有用）；
- 若**早早压平** → **撞噪声天花板**（再多数据也没用，别刷卡）。

## 二、结果

| 任务 | N 从小到大的精度 | 判定 |
|---|---|---|
| **spaceship（n=221，唯一测得动的）** | 0.13 → 0.17 → 0.19 → 0.15 → 0.19 → **0.19**（N=25→150，N=75 后基本压平，误差 ±0.12） | **撞噪声天花板** |
| nomad（n=37） | 0.35 → 0.29 → 0.47（N=12→24，末段跳 +0.18，但误差 ±0.15–0.27） | 点估"还在升"、但太噪不可信 |
| tps（n=31） | 0.09 → 0.17 → 0.15（误差 ±0.42–0.54） | 纯噪声、测不出 |

**最可信的信号（spaceship，样本足）：probe 在 N≈75 就压平了。**

## 三、结论

- **同一批任务上多刷卡 → 更好的 probe：spaceship 说不行（噪声天花板）。** → 借一堆卡去刷这 3 个任务的更多卡，换不来更强的 critic。
- **精确边界（诚实）**：A2 测的是"同任务内多给数据"；它**没测**"更多**不同**任务 → 跨任务泛化"（那是广度问题），也没测（本项目禁止的）微调 LLM。但 spaceship 的噪声天花板说明**单任务信号本身有上限**。
- nomad 的"还在升"是 3 个噪点上的假象，且 nomad 生成本身撞算力墙（agent 起草 GNN 崩），不足为凭。

## 四、和 A1 / Stage B 合起来

- **A1**：probe ~76% 是可读好实践，但扣掉后仍剩 **0.20** 的微妙因子 → 稀疏化 / SAE 被正当触发。
- **Stage B**：生成侧离线测不动（42 条边）。
- **A2**：同任务噪声天花板 → 堆同任务卡不涨 probe。

→ **信号真实但有上限、堆同任务数据抬不动；生成侧没数据可离线判；唯一还没挖、又被原则性触发的新方向是 SAE（定位那 0.20 的微妙因子）。**
