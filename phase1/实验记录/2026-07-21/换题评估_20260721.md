# 项目现状与换题方案（给学长 · 2026-07-21）

## TL;DR
"穷算力噪声鲁棒 MLE 搜索 + reasoning-critic / 冻结探针"这条线，我们已做到能**诚实判定**的程度：
**三条独立证据线收敛 → 此方向没有干净的顶会正面。** 据此**换题，定为 A（数据集/benchmark 论文）**。
**A 已过两道闸门**：novelty 🟢（搜索树数据无人发布 + MLE-Dojo 证顶会可发）、licensing 🟢（可发派生元数据）。
剩下唯一硬前置 = **规模/借卡**（学长的资源 call）。本文给证据、两闸结论、以及 A 的执行方案。

---

## 一、做了什么 + 唯一的干净正结果
- 平台：facebookresearch/aira-dojo（MLE-bench agentic 搜索：MCTS/greedy/evo × draft/debug/improve 算子 + 外部 pristine 评分）。
- 底座：DeepSeek（OpenAI 兼容 API）**冻结、不微调**（model-agnostic 是卖点）。单卡 3090。
- **唯一干净正结果（H1）**：冻结中层表征能**线性解码一个候选解的真实外部 grade**，且**独立于 agent 的自报验证分**、扛得住代码长度残差化。

## 二、为什么它到不了顶会（三条独立线收敛）
**① 深度文献调研（12 条经对抗验证的事实、23 源）——邻域已被 2024-26 工作占满：**
| 相邻方向 | 占用者 |
|---|---|
| 执行前预测候选质量 | I-MCTS（frozen-prompt，且从没验证准不准）、ForeAgent、SWE-RM |
| 给 agent 训小 PRM / 冻结探针当 PRM | DataPRM、AgentPRM、**ReProbe（ACL'26，<10M 探针打平 810× PRM）** |
| 冻结表征查代码正确性 | **VeriLoC（NeurIPS'25）**、Internal-Rep-of-Code-Correctness（Dec'25） |
| RL 训 ML-agent | ML-Agent |

最好的空隙只到 borderline/workshop；且最新文献把"冻结底座"整个范式框成"旧范式"（顶会审稿默认偏见）。

**② 便宜实测（0-GPU）——H1 的正结果不可用：**
- 探针选择候选**打不过免费自报分**（spaceship 0.24 vs 0.44，且数据鲁棒、加数据不闭合）；
- 机制抓手弱：SAE 因子**弥散**（max |corr|=0.22，无可命名维）、activation steering 效应量**可忽略**（比 nuisance 方向还小一个量级）。

**③ 跨模型 make-or-break（实测，3 模型家族 Qwen-Coder/CodeLlama/deepseek-coder，同 395 卡）：**
"decodable≠usable"**跨模型 robust**——但本质是**弱探针 redundant 于强自报分**，不是"知识因果惰性"那个能扛顶会的现象；且只在 2 个干净 tabular 任务上。

## 三、可复用的资产
- **★ 廉价多账号容器数据采集**（commodity GPU）——真护城河。已自持产出 **~400 张带标签搜索节点卡**（代码/自报分/真分/树血缘/算子），大厂不屑在这种硬件上做。
- 冻结探针 + 小 critic 训练管线；aira-dojo 基建；一套噪声鲁棒 + 对抗验证的方法论。
- **顺手修的数据 bug**：medal 阈值归一把"agent 没拿奖"的任务标签压成常数（tps-may 原始 AUC 0.78-0.94 其实有方差）→ **per-task min-max 已修，别丢这批数据**。

## 四、为什么选 A（对比其它换题选项）
- **A｜数据集 / benchmark（NeurIPS D&B / ICLR）** —— 把护城河**直接变成交付**。**novelty bar 低（有用即可）+ 护城河直接命中 → 最高 EV**。✅ 选它。
- B｜跳出 MLE 换全新问题 —— EV 未知，要更广的深搜。
- C｜well-powered 负结果账本 —— 顶会主 track 大概率不收。

## 五、两道闸门结论（2026-07-21 已核）
**闸① Novelty = 🟢 缺口真开**（我用 WebSearch/WebFetch 直接核，因 deep-research workflow 崩在 API 限）：
- aira-dojo（Meta）只发 framework+agents；**MLE-Dojo（NeurIPS D&B 2026 accept）只发 Gym env、明说"不是预算好的 trajectory 数据集、要自己 run"**；MLE-bench 是 benchmark spec；ML-Agent 的 ~10k trajectory 是 RL 训练用、线性、release/结构未确认。
- → **无人发布带完整搜索树结构 + 外部真分 + 多模型的 MLE-agent 数据集**；且 MLE-Dojo 证明该主题能上顶会 D&B。

**闸② Licensing = 🟢 可发布（有明确设计约束）：**
- **DeepSeek 生成代码**：ToS 明确**把 output 权利归用户**，且**准许学术研究/派生开发/蒸馏** → 我们的解代码可发布（标注 AI 生成即可）。
- **MLE-bench / Kaggle 数据**：底层数据有逐赛题限制（MLE-bench 自己就排除了部分）→ **我们不发数据本身，只发派生元数据**（代码 + 标量真分 + 树结构 + 自报分 + 算子）。
- **安全发布设计**：①只发代码+分数+结构、**绝不含 Kaggle 数据**；②逐赛题过滤（只收许可派生/公开的，同 MLE-bench 做法）；③脱敏代码里任何嵌入的数据样本；④标 AI 生成。

## 六、A 的执行方案（build-plan）

**数据点 = 一棵搜索树里的一个候选解节点**（schema 已齐）：代码 / 自报分 / 外部真分（原始+medal+min-max）/ buggy+traceback / exec 时间 / 算子 / 父节点+深度+子节点 / 搜索策略 / seed / 底座模型 / 任务元数据。

**规模 + 多样性目标：**
| 维度 | 现状 | 目标 |
|---|---|---|
| 任务 | 4 tabular | 15-30 多样（tabular+图像+NLP；已 prep 5 广度） |
| graded 节点 | ~400 | 上万级 |
| 多样轴 | MCTS×1 底座 | 任务×seed×**搜索策略(MCTS/greedy/evo)**×**多底座模型** |

**算力账（诚实）**：单节点(3 槽)≈130 graded/天 → 上万要 ~2-3 月，太慢。**借 16-24 卡(多账号容器)≈10-15 天，可行。→ 借卡是硬前置。**

**差异化 vs MLE-Dojo（审稿人必问）**：静态/curated/免算力 + 多模型(model-agnostic) + 完整树结构+外部真分 + 自带演示分析（研究 critic/credit-assign/噪声零算力就能做，而自己 sample 正需要那个算力壁垒）。

**演示分析（把旧发现变成"数据集能干嘛"的 baseline）**：从代码预测真分（decodable≠usable）；评估噪声(self-report vs 真分)；算子/credit assignment。

**阶段**：
- 阶段 0（几天，多免算力）：licensing 已核✅、广度 smoke 确认能产 graded、min-max 设默认、schema/datasheet 骨架、**学长敲定借卡**。
- 阶段 1（~2 周，吃借卡）：广度+多模型+多策略跑满 → 上万节点。
- 阶段 2（~1-2 周）：schema 定稿+划分+datasheet+演示分析。
- 阶段 3：写 D&B 论文。

**风险**：规模依赖借卡；"静态 dump"质疑靠多模型+树结构+演示分析回答；被 Meta 抢发 → 要快。
