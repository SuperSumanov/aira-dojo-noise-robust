## 二、任务推荐(快速迭代)

**✅ 推荐(离线容器下 ≤18min/run、能产真分)**:`us-patent` · `chaii` · `google-quest` · `essay-scoring-2` · `tweet-sentiment`(5 个 NLP;报错全是 agent 可自修的代码错,多步搜索能恢复)。

## 三、基建发现(按重要性;①②已在我们 worktree 打补丁)

1. **`srun_pool.py:117` symlink bug**:`Path(sys.executable).resolve()` 把 uv-symlink venv 的 python 解析成基座解释器 → worker 丢 venv(`No module named omegaconf`)。**修:`.resolve()`→`.absolute()`**。
2. **容器 env 机制**:新 `singularity_jupyter_server` 只用 `jupyter.yaml` 的 `env:` 配置(sand 的 `RAD_*` 那套不再生效);且 **`HF_HUB_OFFLINE=1` 是显式设计** → 所有预训练下载必崩是预期行为。**我们在 operator prompt 里加了"离线环境,勿用预训练"警告**,v3 里 NLP 任务立刻从全崩变为能产真分。
3. **timm/EfficientNet"必报错"的两个根因候选**:(a) `HF_HUB_OFFLINE=1` 挡权重下载;(b) **容器 GLIBC 太旧**——kuzushiji/petfinder 报 `ImportError: /lib/x86_64-linux-gnu/libc.so.6: version GLIBC_2.3x not found`(二进制 wheel 需要更新 glibc)。(b) 是镜像构建问题,重构 .sif 时需换 base 或钉旧版 wheel。
4. **坏节点**:`gpu36` = 容器启动静默冻死(复现 2 次,4并发与串行都冻);`gpu38` = 跑一半 node failure 拖死整个 allocation。**建议 salloc 排除**。(projgpu 系列 + gpu37/39 正常。)
5. **srun_pool batch 复用坑**:同 config 重跑会复用旧 manifest/snapshot(重试耗尽直接 fail)→ 失败后要换 `metadata.git_issue_id`。
6. **大数据任务盘溢出**:kuzushiji(4.5GB)在节点 tmp 撞 `No space left on device`。
7. **statoil prepare 缺口**:MLE-bench 对该赛题保留 `.7z` 压缩包,与"不要解压"的 agent 指令冲突 → prepare 阶段应解压。

## 四、复现命令(供参考)

```bash
salloc --account=gpu --qos=gpu --partition=gpu_8h --nodes=1 --ntasks=1 \
  --cpus-per-task=6 --gpus-per-node=1 --exclude=projgpu8,projgpu33,gpu36,gpu38 --time=08:00:00
# 进 allocation 后:
python -m dojo.main_runner_job_array +_exp=runner_example \
  'benchmark.tasks=[<task>]' 'vars={metadata.seed:[42]}' \
  'solver/client@solver.operators.{analyze,debug,draft,improve}.llm.client=litellm_deepseek_flash' \
  solver.execution_timeout=1500 solver.time_limit_secs=5400 \
  metadata.git_issue_id=<fresh-id> launcher=srun_pool '~launcher.qos' \
  launcher.max_parallel=1 launcher.cpus_per_step=6 launcher.gpus_per_step=1 \
  launcher.min_remaining_seconds_to_launch=600 logger.use_wandb=false
```

**环境补充**(worktree `.env`):`HARDWARE="1 NVIDIA GeForce RTX 3090 GPU (24GB VRAM) and 6 CPUs"`(operator prompt 的 `{{hardware}}` 从它读)。
