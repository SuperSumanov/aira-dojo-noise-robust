# 方案 A 汇报:MLE-Agent 搜索树数据集(计划全文 · 2026-07-23)

> 目标:发布第一个**大规模、富标注的 LLM-agent ML 工程搜索树数据集**,投 **NeurIPS Datasets & Benchmarks / ICLR**。
> 一句话定位:大厂在数据中心里天天生成这种搜索轨迹但从不发布;我们用 commodity GPU + 容器多账号,把它做成社区资源。

---

## 一、为什么是它(三道闸已过)

**1. Novelty 🟢(已核,2026-07-21)**
- aira-dojo(Meta)只发布 framework + agents,**没发搜索数据**;
- **MLE-Dojo(NeurIPS D&B 2026 accepted)只发 Gym 环境**,明说"不是预算好的 trajectory 数据集,要自己跑"——同时证明了**这个主题能上顶会 D&B**;
- MLE-bench(OpenAI)是 benchmark 规范;ML-Agent 的 ~10k 轨迹是线性 RL 训练用、未确认发布、无外部真分;Nebius 发的是 SWE 轨迹(非 MLE、非树)。
- → **"带完整树结构 + 外部真分 + 多模型的 MLE-agent 搜索数据"没人发过。**

**2. Licensing 🟢(已核)**
- DeepSeek ToS **把 output 权利归用户**,准许学术/派生用途 → 生成代码可发布(标注 AI 生成);
- 我们**只发派生元数据**(代码+标量分数+树结构),绝不含 Kaggle 原数据;逐赛题过滤(照 MLE-bench 做法)+ 代码脱敏。

**3. 顶会有趣度的诚实定位**
- D&B 的 bar 是"**有用**"而非"惊人发现"——这正好绕开我们反复被卡死的地方(此前三条线收敛:邻域内没有便宜的'有趣'正面);
- 竞品问题("有 MLE-Dojo 环境为何要静态数据")有明确回答,见 §四。

## 二、数据集本体

**一个数据点 = 搜索树中的一个候选解节点**:

| 类别 | 字段 |
|---|---|
| 解 | 完整代码、自报验证分、**外部真分**(原始 + medal + per-task min-max)、buggy 标志 + traceback、执行时长 |
| 树 | 生成算子(draft/debug/improve/crossover)、父节点、深度、子节点、UCT 探索轨迹、seed |
| 环境 | 任务元数据(类型/指标/牌线)、**底座模型配置**(v4-pro 混合 vs 全 flash)、**执行环境**(python 子进程 vs 容器 Jupyter)、搜索策略、git commit、完整 config |

**多样性轴(数据集的价值所在)**:任务(tabular/NLP/图像)× seed × 搜索策略(MCTS 为主,可加 greedy/evo 臂)× 底座模型 regime × 执行环境。每轴都在 `dojo_config.json` 里可溯源。

## 四、对审稿人必问的"vs MLE-Dojo"

> "有环境自己跑就行,为什么要你的静态数据?"

1. **免算力**:研究 critic/credit-assignment/评估噪声,用我们的数据零 GPU 就能做——自己 sample 恰恰需要我们论文里量化的那个算力壁垒(单任务单树 2-4 GPU 时 + 全套基建调试);
2. **一致标签**:统一的外部 pristine 评分 + medal + min-max 三层标签,自己跑难以对齐;
3. **多模型/多环境轴**:个人复现通常只有一个配置,我们横跨 2 模型 regime × 2 执行环境;
4. **树结构**:MLE-Dojo 采样的是交互轨迹;我们发布的是**带 UCT 血缘的搜索树**——credit assignment / 树上价值学习的天然材料;
5. **演示分析**(§五)证明"能用它答什么"。

## 五、演示分析(旧成果全部废物利用)

1. **从代码预测真分**(冻结探针 baseline + 跨 3 模型家族的 decodable≠usable 现象)→ 数据集的第一个 benchmark 任务;
2. **评估噪声解剖**:自报分 vs 真分的背离结构(我们有 +0.73 edge 相关 + 少数派幻觉的实测);
3. **算子/credit assignment**:哪类算子在树的哪个深度创造价值;
4. **预算层级稳定性**(引用 Efficient-Benchmarking/Pace 等 2026 工作的协议,在我们数据上离线复算)——**降级为 enabled-analysis,不声称协议 novelty**;
5. 离线 regime 的任务难度反转观察(测评 §五的奖牌数据)。

## 六、执行计划(算力账诚实)

**现状**:~500 卡(tabular 4 任务)+ pool 线两批 140 节点/38 graded;两条自持线 ~200 graded/天(单账号 7 卡)。

| 阶段 | 内容 | 时长 | 依赖 |
|---|---|---|---|
| P0(本周) | 补 prep plant-pathology + text-norm-en(需在我们 Kaggle 账号接受规则);suite 定稿;pool 线切到 suite | 1-2 天 | 你点两次规则 |
| P1(采集) | suite × 8-13 seed × MCTS-20 步;+greedy/evo 小臂;两模型 regime | **借 16-24 卡:10-15 天;单账号:~50 天** | **学长:借账号数量拍板** |
| P2(打包) | schema 定稿、train/val 划分、datasheet、脱敏、逐赛题 license 过滤 | ~1 周 | — |
| P3(分析+写) | §五的 5 个演示分析 + D&B 论文 | ~2 周 | — |

**规模目标**:≥10k graded 节点、12+ 任务、≥2 模型 regime、≥2 执行环境、3 搜索策略。(对照:我们 289 卡时代的所有欠功率教训——这次数据量就是产品本身。)

## 七、明确不做什么(踩过的坑直接变护栏)

- **不做**"廉价 suite 预测贵评估"的协议论文——tinyBenchmarks/Efficient-Benchmarking(2603)/How-Many-Tasks(2607)/Pace(2607)/Claw-Lite(2606)已占满,我们只引用;
- **不做**"我们的聪明搜索赢 baseline"——AIRA 负结论 + 深搜三轮确认的死路;
- **不在生成器里掺自制组件**(探针/critic/steering 全部实测不达标)——生成器保持 vanilla aira-dojo,自制组件只活在演示分析里;
- **不赌** PRM/critic 训练出奇迹——数据够了以后那是 gated 的后续,不是本篇。

## 五·补(2026-07-23):训练效用证明(回应"不能只甩数据")

D&B 审稿的现实:纯数据 dump 会被质疑,**必须训过、证明有用**。三层设计(风险递进):

| 层 | 内容 | 算力 | 风险 |
|---|---|---|---|
| **T1 规模曲线** | 冻结特征+小头训三预测器(真分/buggy/hack检测),画**性能 vs N 曲线**(300→3000+) | 零 GPU 增量(管线现成) | 低——A2 已证 probe 随 N 涨;buggy 预测大概率强信号 |
| **T2 树结构独有** | debug-恢复预测(血缘给标签)、算子条件化价值增量 | 零 GPU 增量 | 低——只有树数据能做,即差异化 |
| **T3 闭环旗舰** | 数据训小 critic(冻结特征+头/LoRA 小模型,底座不动)→ 塞回 MCTS 做节点选择,留出任务双臂对照 | ~10-20 树×2 臂,pool 线 2-3 天 | 中——289 卡时代 probe 输自报分是前车之鉴;**gate:T1 曲线仍升 + 数据 ≥2-3k 才跑** |

**叙事纪律**:T1 卖"信号随数据增长"(曲线即效用证明),不卖"critic 赢一切";T3 正=杀手 demo(且正面回答学长假设1——他的 PRM 想法以效用证明身份回归),负=如实报,T1/T2 已够撑效用。**训练全部发生在数据集之上的小模型,底座 LLM 仍冻结(model-agnostic 不破)。**


## 十、设计修订(2026-07-24:学长反馈 + 外部评审采纳)

**定位收紧(应对 ForeAgent)**:zjunlp 已发布 18,438 个 pairwise 对(github: predict-before-execute,
单次执行真分、扁平对、无树/无方差),且宣布 RM training 为下一步 → "纯节点数"不再是安全卖点。
**本数据集的护城河改为结构性特征**:搜索树 + 多 seed + **噪声标注(re-grade 臂)** + 双执行环境/双模型 regime 轴。
**一等公民问题改写为:"一个 MLE 解质量的 RM,需要多少、什么结构的数据才能训起来?"**
(RM-accuracy-vs-N 扫描 + 噪声天花板 = 无论数字好坏都有着陆点。)

**① Re-grade 臂(已实现,edge 在跑)**:每任务分层抽 ~24 个 graded 节点,同容器同环境**重执行 K=3-5 次**
+ 外部重评分 → per-task 噪声地板 τ + 每 grade 方差条。产出:噪声标注语料(ForeAgent/Meta 默认基建都没有)、
有效对过滤门槛、noise-weighted BT loss 的权重来源。工具:`phase1/regrade_select.py` + `scripts/regrade_worker.py`
+ `scripts/regrade.sbatch`。**约束:必须与采集同环境同版本,故与战役并行跑,事后无法补。**

**② ForeAgent 噪声天花板分析(RM 训练前置)**:下载其 18k 对,按 |grade gap|/τ 分层画 accuracy-vs-gap
→ 量化 "61.5% 里多少撞了不可约噪声" = 论文级洞见 + 保护我们自己的 RM 数字("可达上限的 X%")。

**③ 泄漏设防**:in-task + cross-task(LOTO)双报告;**风格泄漏 killer check**=在他们双模型语料内按生成模型切开
(RM 在 DeepSeek 解 vs o3-mini 解的 accuracy 差);train/eval near-dup 过滤(minhash)写进 datasheet。

**④ 北极星指标换为 effective-pairs/GPU·时**(过 τ 的对 + 跨档对),按它每周重分配 worklist;
**分配策略=广度优先**(12 任务先各 150-300 graded,再按 T1 曲线仍升者加深);
provenance 字段(采集线/模型 regime/执行环境/HF 在线离线)已随 dojo_config 记录。

**⑤ T3 战场选择必须来自 (σ,Δ) headroom 图**:tps-dec(0.31)/spooky(0.19)/google-quest(0.21);
明确不在 spaceship 上跑 T3(自家 headroom≈0 结论预测其必 wash)。

**⑥ 定版决定**:v1 范围=**tabular + NLP**(视觉诚实排除,不留期票);card id=32-hex uuid,
多账号合并无需加盐(已核);T1 曲线每周重跑作为分配传感器。

## 十一、训练支柱(2026-07-24 草案,待学长确认;回应"纯数据还差一点"+ ForeAgent 竞争)

**定位升格:数据集(D&B)+ 首个"MLE 解质量 RM"系统训练研究,双支柱。**
底座生成器仍冻结;所有训练只发生在独立小模型(LoRA / ≤2B,单 3090 可跑;学长已放行 PRM/critic)。

四个训练实验(风险递进,前两个 = 核心卖点):
1. **RM-acc-vs-N 数据需求曲线**(in-task + LOTO 双报):"训起一个 MLE RM 要多少、什么结构的数据"——一等公民问题的直接实证;
2. **噪声感知训练**:τ-加权 / τ-过滤 BT loss vs 朴素 BT——唯一持有 τ 标注(re-grade 臂),ForeAgent 单次执行分无法复现此消融;
3. **树结构信号**:血缘/兄弟对比目标 + debug-恢复预测(=T2)vs 扁平 pairwise——树数据独有;
4. **跨语料外测**:ForeAgent 18,438 对作外部测试集 + 按生成模型切开的风格泄漏检查——竞品变考卷。

护栏:pilot RM(LoRA 小模型)在 ~2k graded 后启动;正式曲线等 ≥5k(289 卡欠功率教训);T3(critic 回插搜索)gate 不变;与 ForeAgent 的区隔=他们"训一个 RM",我们回答"RM 需要什么数据"。

> **2026-07-25 学长批复(§十一 生效)**:"相当于测一遍 reward model 的最佳配比,方案是可以的。"
> ①训练支柱**批准**;②算力路线:**先 3090 做前期验证**;quota 不够可分一个 MLE 任务给他腾配额;
> 需要长 context / 全精度时他去排 **H200**;③**他的采集主力已点火:18 卡在跑,下周增至 ~30 卡**
> (超过计划 16-24 卡假设,P1 时间线按 30 卡重估)。

> **claim 校准(2026-07-27,ForeAgent 语料实测核验)**:其 HF release 的 agent_runs 里,AIDE 节点 metadata 含
> `parent_id`(树血缘)、eval_output.json 为逐节点官方 MLE-bench 真分(含 medal 阈值),且每任务 ~3 次运行。
> **因此弃用"首个 MLE 搜索树数据"强表述**。校准后的差异化:①**逐节点噪声地板 τ(K 次同环境重执行)= 独家**
> (他们全部单次执行);②双执行环境轴 + 环境脆弱性标注 = 独家;③任务域互补(我们 tabular+NLP,他们重视觉);
> ④搜索策略互补(MCTS-UCT 带访问统计 vs AIDE/AutoMind/ForeAgent);⑤一等公民问题(RM 数据需求曲线+噪声
> 天花板)不受影响,反而因其语料可作跨域外测而增强。
