## 二、独家标注:τ 噪声地板(re-grade 臂,已完成 v1)

**做法**:每任务分层抽 24 节点,同容器重执行 K=3 + 外部重评分;288 条全部落库(`regrade_tau_nodes.csv`)。

**发现**(四任务一致):
1. **τ 三档结构**:69-90% 节点三次重跑**逐位相同**(τ=0);少数微小 τ(10⁻⁴~4×10⁻³);全语料仅 1 个剧烈随机节点(nomad,τ=1.05,吞掉任务 12% 分数范围);
2. **同环境噪声 ≤ 分数范围的 ~1%** → 执行分可以放心当标签;
3. **真正的不确定性是"换环境能不能跑"**:54/288 重跑失败,几乎全是包偏移(LightGBM-OpenCL 18、sklearn API 3)与 cap 截断——"环境脆弱性"是离散标注轴,不是连续漂移(确定性节点跨环境分数逐位复现,中位偏移=0)。

**v2 已在跑**(job 8153):233 节点覆盖 suite 任务(petfinder/pizza/leaf/spooky/quest/tweet/text-en/whale),2-3 天出全表。**规划中**:regrade-B 补臂(原环境重跑 54 个失败节点,给它们干净 τ)。

## 四、与 ForeAgent 的关系(实测核验后的 claim 校准)

他们 HF release 实测:AIDE 节点带 `parent_id`(树血缘)、逐节点官方真分、每任务 ~3 run。**故弃用"首个搜索树数据"强表述**。校准后的差异化:

1. **逐节点 τ(K 次同环境重执行)= 独家**——他们全部单次执行,物理上无法补;
2. **双执行环境轴 + 环境脆弱性标注 = 独家**;
3. 任务域互补(我们 tabular+NLP,他们重视觉)+ 策略互补(MCTS-UCT 带访问统计 vs AIDE/AutoMind);
4. **一等公民问题换位**:不比"谁的数据多",回答"**训起一个 MLE RM 需要多少、什么结构的数据**"(RM-acc-vs-N + 噪声天花板,两头着陆);
5. 他们的 18k 对反手变成我们的**跨域外部测试集**。
