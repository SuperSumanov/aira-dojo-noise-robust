# 论文重构:从"我们发了个语料"到"我们提出一个新任务 + 它需要的数据"

## 一句话定位

**Lookahead node selection for MLE agents**:给定一个搜索树中的部分解、剩余预算(时间/硬件/agent),
预测**哪个节点通向更优的最终解**。这个任务**只能在带血缘和外部真分的搜索树上定义**,
因此我们同时提供:任务形式化、可训练的数据、噪声上界、基线,以及下游效用验证。

## 为什么这不是 ForeAgent 的换皮(可量化)

| | ForeAgent (2601.05930) | 本文 |
|---|---|---|
| 任务 | 两个**完成的解**谁更好 | 树中两个**节点**谁通向更优解 |
| 数据形态 | 895 个带标签解 → 18,438 个扁平对 | 2,162 个带真分节点 + 完整血缘(深度中位 5,最大 36) |
| 标签 | 单次执行分 | 子树最优分(可按预算截断)+ **每节点噪声地板 τ** |
| 两任务的关系 | — | **26% 的对上两个任务的答案相反**;逐节点自身分与子树最优分相关性仅 0.13–0.60 |

→ 新任务的 26% 是旧数据**物理上无法覆盖**的部分。这是 novelty 的量化定义,不是叙事。

## 论文骨架

**§1 任务**:形式化 lookahead node value:`V(n | B) = best score over descendants reachable within budget B`。
预算维度(步数/GPU 秒/硬件档)使它对搜索算法不可知——MCTS 只是数据生成器之一,
框架对任何产生轨迹/树的 agent 都成立(回应"MCTS 会被淘汰"的合理担忧)。

**§2 数据**:多任务 × 多 seed × 多执行环境 × 多温度 regime 的搜索树语料。
关键字段:代码、自报分、外部真分(MLE-bench 官方 + 奖牌阈值)、算子、父/子/深度/兄弟、执行元数据。

**§3 标签可靠性(独家)**:re-grade 臂 = 同环境 K 次重执行 → 每任务噪声地板 τ。
结果:τ 三档(69–100% 节点逐位确定;少数微小;极少数剧烈),有效对占 94.6–100%。
→ 给出"标签本身有多可信"的量化上界,这是任何 RM 结果的必要脚注,而竞品无法提供。

**§4 基线与发现**
- (a) 同任务内可学且随数据量单调升:0.535 → 0.757(N=500→24k);
- (b) **跨任务几乎不迁移**:5 折 0.51–0.61,即使加任务条件化和 2 倍上下文;
- (c) **两类数据互补**:跨任务预训练 + 目标任务 1000 对 = 0.707,单用任一条 ≈ 0.62;
- (d) **新任务可学且非捷径**:泄漏受控下分歧对 0.609(捷径基线 0);
- (e) **方法学警告**:按节点切分会虚高 21.6 个百分点 → 使用本数据必须按树切分。

**§5 下游效用(决定投稿层级)**:value-RM 插回 MCTS 节点选择,双臂对照(同预算、同算子、同底座)。
赢 → ICLR 形态;平 → 诚实报告为"当前规模下不足以改善搜索",退 D&B。

**§6 可复现性 / 环境异质性**:四种机制的实证链——包不可用(LightGBM/OpenCL,18 例)、
磁盘、显存(2080Ti OOM)、运行时可用性(容器与大显存节点互斥)。
→ 论点:异质性应当被**记录和建模**,而不是被假装消除。附上给 aira-dojo 上游的具体建议。

## 与旧定位的取舍

- **降级**:"最大的 MLE 搜索树数据集"(规模上我们不占绝对优势,别拿这个当主卖点);
- **升级**:"新任务 + 使其可训练的数据 + 噪声上界 + 使用规范";
- **保留**:数据集本身作为 §2 的贡献,但服务于 §1 的任务定义。

## 还需要补的(按对投稿层级的影响排序)

1. **下游效用(§5)** —— 决定 ICLR 还是 D&B;
2. **第二个生成器家族** —— 现在全部是 DeepSeek,"多模型"名不副实;补上后可做**跨生成器迁移**实验(比跨任务更能说明表征问题),并支撑风格泄漏检查;
3. **预算轴的完整扫描**(B = 1/3/全子树)—— 目前只建了 B=3 和无限两档,应给出 V 随预算变化的曲线;
4. 规模:2,162 → 5,000+(边际收益低于 1 和 2,但曲线右端更稳)。
