# 实验结论汇报(2026-07-31,给学长,决策用)

> **一句话**:主要发现全部落地且经过审计——**MLE 奖励模型存在"双重不泛化"**(跨任务弱、跨生成器完全失效),
> 修复它的数据代价已量化;你提的 lookahead 任务成立(泄漏受控后仍显著高于捷径);T3 搜索内引导 = null(诚实报)。
> 语料 3,202 张真分卡 / 20 任务 / 2 生成器。**待决策:是否按 8 周冲 ICLR(发现为主角),D&B 5 月为备胎。**

## 一、语料现状

**3,202 张带外部真分的节点 / 20 任务 / 2 生成器(DeepSeek + Qwen)**,100% 带树血缘(真实深度中位 5、最大 36)。
大头:birds 920 / tps_may 446 / nomad 341 / petfinder 267 / denoising 225 / spaceship 224。

## 二、核心发现:RM 的双重不泛化(全部经过体内对照审计)

**(a) 同任务内:学得会,且随数据量单调升**

| 训练对数 N | 500 | 2,000 | 8,000 | 24,000 |
|---|---|---|---|---|
| 准确率 | 0.535 | 0.605 | 0.746 | **0.757** |

(运行间噪声 ±0.002,实测。)

**(b) 跨任务(LOTO 五折):几乎不迁移** —— 0.511 / 0.520 / 0.525 / 0.597 / 0.613,对照同任务内 0.769。

**(c) 跨生成器(同任务!):完全失效** —— DeepSeek 训的 RM 判 Qwen 解:**0.496(纯随机)**。
- 审计:同一模型同一次运行,DS 留出对 0.64-0.76、Qwen 对 0.47-0.50 → 管线无罪,发现坐实;
- 已排除:标签方向错、id 碰撞、训练泄漏、分数尺度、代码字段污染、"Qwen 对更难"(大分差子集同样失败);
- **例外**:tps_dec 完美迁移(0.653 vs 0.644)——解空间最模板化的任务不绑定。
  → 结论精细化:**风格绑定的程度取决于任务解空间的同质性**。

**(d) 修复代价已量化(治愈曲线)**:
- 混入 ~160 个 Qwen 对(占训练 2%)→ 无效(0.486);
- **551 对两阶段微调 → 0.566**(+6.7 点,≈2.9σ);
- 参照 LOTO 少样本:~1,000 对 → 0.657-0.707;
- **预训练与目标数据互补可叠加**:大基座(N=24k)+ 1,000 目标对 = **0.707**,单用任一条 ≈ 0.62。

**含义**:这类 RM 学到的是"特定生成器×特定任务的风格-分数关联",不是可迁移的质量概念。
ForeAgent 语料以 o3-mini 为主 → 按此结果推断其后续 RM 也会绑死风格,且单生成器语料**测不出**这个问题。
**多生成器数据从卖点升格为必需品,且必要性有价格标签。**

## 三、你提的 lookahead 任务:成立,且给出了使用规范

- 可行性:节点自身分与其子树最优分的相关性仅 0.13-0.60(除饱和的 spaceship 0.96)——**不是质量任务的换皮**;
- **26% 的节点对上,"现在谁好"与"谁通向更好"答案相反**;预算越大分歧越大(1 步 15.2% → 全子树 21.1%,
  执行时间预算轴同形状)——预算是任务定义的实质部分,框架对搜索算法不可知(不依赖 MCTS);
- 训练结果:分歧对(捷径模型必得 0 的那部分)准确率 **0.609-0.617**(树级切分,两个 N 复现一致);
- **方法学警告(本身是贡献)**:按节点切分会虚高 21.6 个百分点(0.825→0.609)——血缘上相邻节点代码
  高度相似,**使用这份数据必须按树切分**。我们有量化证据。

## 四、T3(RM 插回搜索):null,如实报

8 个 seed 配对 run(spooky+tps_dec,唯一变量=选择时是否咨询 value-RM,处理臂带交付证明仪表):
**引导 4 : 对照 4**,且 tps_dec 的全部差异(±0.0006)低于我们自己 τ 表的噪声地板。
机制归因:RM 分歧对准确率仅 0.61 × 每 run 仅 ~5-6 节点被打分 × 20 步小预算 = 测不出效应。
**这与 §二 的发现互洽**:RM 学不到可迁移价值 → 插回搜索无效 → 恰好论证"需要什么数据"是对的问题。
