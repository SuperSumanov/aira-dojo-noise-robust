**数据**:`decision_pairs_v1.jsonl` — 决策集 = 同父的 ≥2 个有真分子节点(= MCTS

按树切分。1,496 个决策集 → 4,592 对(K0 3,529 / K1 569 / K2 494),test 侧 847 对。

**结果(同一 847 test 对):**

| 打分者 | overall | len-ctrl | K=0 | K=1 | K=2 |
|---|---|---|---|---|---|
| 1.5B@2048(决策对上训练) | **0.5726** | 0.5495 | 0.575 | 0.559 | 0.574 |
| 0.5B@6144(决策对上训练) | 0.5384 | 0.5290 | 0.548 | 0.510 | 0.500 |
| **自报分 val_at_low(免训练)** | **0.731**(覆盖 95.6%) | — | **0.777** | 0.559 | 0.581 |
| code_len / runtime / step_order | 0.504 / 0.524 / 0.515 | — | — | — | — |

per-task(1.5B):spooky 0.581(472)/ petfinder 0.648(145)/ birds 0.493 /
nomad 0.455 / chaii 0.353(反向)。自报分 per-task:spooky 0.722 / petfinder 0.746 /
birds 0.738 / nomad 0.750 / leaf 0.840 / chaii 0.548。

**判读(核心发现,排序反转):**
- 全局池上 RM 0.828 ≫ 自报分 0.6345;**决策对上自报分 0.731 ≫ RM 0.573**。
  部署决策点的信息排序与全局评估完全反转。
- 覆盖差异不构成解释:自报分缺失仅 4.4%,最坏情形下 RM 在被覆盖子集 ∈ [0.553, 0.599],
  仍远低于 0.731(界算:847 对中 485 命中,37 对未覆盖全对/全错两个极端)。
- RM 显著高于随机(0.5726,n=847,z≈4.2)——兄弟级信号**存在但弱**;
  K≥1(「哪个孩子通向更好子树」)所有打分者都接近随机(0.55-0.58)——真正的
  前瞻问题目前无人能答,是数据集使能的 open problem。
- 0.5B@6144 全面弱于 1.5B@2048:**长 context 不是决策对的瓶颈**(学长建议 #2 的答案),
  容量占主导。
- 机制链闭环(四个结果一个故事):L1 全局 0.83 → 方差分解(lineage 间份额 0.73,
  MCTS 放大)→ 决策点塌缩(RM 0.57 < 自报 0.73,lineage 身份被条件化移除)→
  T3v2 引导搜索 null(p=0.7461)。**T3 null 不再是遗憾,是被三层机制预言的必然。**

## 2. L2 2×2(job 9664 对角线已知,交叉格 job 9819 在跑)

对角线(各自训练 run 内评):
- v2 模型@v2 flip:mean 0.535/0.574/0.560(K2/K3/K5),switch_acc 0.74/0.83/0.71,
  selectivity 2.2/2.0/2.7;主 acc 0.7113
- v3 模型@v3 flip:mean 0.504/0.509/0.505 ≈ 全平,switch_acc 0.55/0.60/0.55;主 acc 0.7517

**裁决规则(开交叉格之前再次落字,与预注册一致):**
- v2 模型在 v2+v3 两套 flip 上都灵 且 v3 模型两套都不灵 → **训练数据成分**问题
  (v2 标签协议教出了预算敏感,count-matched v3 没教出来)
- v2 模型只在 v2 flip 上灵(v3 上塌回 0.5)→ **评估集特异性**,v2 正结果撤回
- 两个模型在对侧都不灵 → v2 对角线 = 模型×集合的偶然交互,撤回
- 两个模型在对侧都灵 → 预算信号普遍真实,v3 对角线 null 反成异常(可能性低)

### 5.3 切分体检:三层结构问题逐层揭开

1. **跨文件 holdout 不一致**(overlap_check.py):v2/v3/decision/value 各自 builder 独立抽
   holdout → 交叉评估的 81-83% test 对落在对方训练树内。**Cells A/B 作为泛化证据作废**;
   干净 2×2 只剩对角线:v2@v2 弱正(0.533-0.575, switch 0.71-0.83)/ v3@v3 全平
   (0.504-0.511)。L2 章的诚实读法:**count-matched 协议下 flip 效应 = null;v2 时代的
   弱正随标签修正消失,疑似骑在采样强度混杂上**(与 lookahead 标签混杂同源)。
2. **决策集碎片跨界**(dissect_dec_overlap.py):**44% 卡片是孤儿**(父节点无真分被剪),
   孤儿兄弟各自成碎片根、独立抽签 → 49/847 test 对泄漏。修复:decision_pairs.py 全兄弟
   同侧规则(跨碎片 set 丢弃,44 个);v1b 重建后 728 根 0 跨界(verify_v1b.py)。
   三 seed 重训已重发(9835-37,v1b + hits dump)。
3. **物理 run 级泄漏(最重要)**:卡片无 run 字段,但按批文件连续性 + step 回落重建
   run 归属(**457 个 run,双验证 0 违例**,card_run_map.json)。结果:mean 9.1 碎片/run,
   **99.7% 的 in-task test 对与训练侧共享物理 run**(value/budget 全部;decision 94.1%)。
   即:L1 0.828、L2 对角线 0.71/0.75、决策臂,都是「见过同 run 其他碎片」条件下的数字。
   LOTO/迁移表(任务级切分)与 SR 基线(免训练)**免疫**。
