## 11. 正结果全面搜索(2026-08-09):七次尝试全负,但拿到一个可计算的根因和一个真发现

用户要求"搏一搏正面结论"。从"我们一直输在哪"倒推:所有失败共享同一结构——每个实验都是
"学一个模型把节点排得比自报分好",而自报分 ρ=0.812 且免费。突破口只能在**自报分结构上
缺席或失效**处。三条候选,逐条实证。

### 11.1 三条候选的结局(全部零 GPU 判定)

| 方向 | 数据支持 | 结局 |
|---|---|---|
| A 修复价值(失败程序值不值得 debug) | 875 决策 / 53.3% / 8 任务 | **功效死**:883 对实为 202 程序 / 30 run,最佳特征 CI [0.434,0.711] |
| B 预测自报分何时说谎 | within/between=3.60 | **证伪**(见 11.2) |
| C run 级早停 | 381 run / 67.5% 改进 | **CROWDED**:2026 年五篇覆盖(EET@ACL Findings、KompeteAI@MLE-bench、Semantic Early-Stopping 已用我们打算用的协议);自身最佳廉价特征仅 ρ=0.153 |

### 11.2 方向 B 的证伪(预注册,判据开盒前落字)

外部调研指出 within/between=3.60 **无法区分**"程序性质"与"赢家诅咒"(选择噪声同为任务内)。
两项检验:

**P1 run 聚类**:自报分判错的 444 对上 RM 0.5586,但按 run 聚类 CI=[0.4713,0.6246],**跨 0.5**。
**未截断复评**(完整 held-out 侧,3,698 对 / 35 run;原 3,000 上限是省算力设置与假设无关):
效应**反而下降**至 0.5420,CI=[0.4505,0.6024];**去 spooky 后 0.4733(低于随机)**。
两项预注册条件均 FAIL → **「代码含自报分之外的正交信息」被证伪**,非未测出而是不存在。
样本扩大而效应减弱,是真零效应被更精确估计的 signature。

**P2 赢家诅咒——推翻了外部推测(本节唯一正面发现)**:
ρ(兄弟数, |gap|) = **−0.185(负)**;兄弟最优节点 |gap| 反而更小(0.218 vs 0.246);
signed gap 仅 −0.031。**MLE agent 的 val→test gap 不是 best-of-k 选择噪声**,
也不是代码可读属性(控制兄弟数/排名/自报水平后 code_len 偏相关仅 +0.087)。
它主要是 agent 自身验证划分的特异性。

> 这一条直接回应文献中的公开矛盾:AIRA-dojo 报 9–13pp gap,Bertran(2606.11045)报 0.0–1.9pp。
> 我们的数据说两者可共存且成因非选择噪声。**需要恰好我们这种语料才能测**,可独立成节。

### 11.3 within-run 修复:唯一提升功效的设计杠杆,仍 FAIL

跨 run 配对白付 run 级方差;run 内配对可抵消(决策点 p=1.1e-14 即因天然 run 内)。
86 个 run 含互相矛盾的修复结果、2,299 对。`step` 初看过线(per-run 0.683,p=0.0001),
**审计后判为小 run 加权伪影**:

| 限制 | per-run | p | runs |
|---|---|---|---|
| 全部 | 0.683 | 0.0001 | 86 |
| ≥3 对/run | 0.615 | 0.040 | 59 |
| ≥6 对/run | **0.582** | **0.143** | 39 |

19 个 run 仅 1 对(贡献 0/1)。**nomad pooled 0.446(低于随机)vs per-run 0.725** 反向矛盾;
步号分桶无单调趋势(step 0 最高 0.885)。判 **FAIL**(≥3 档技术过线但阈值非预指定、
效应单调衰减、存在反向矛盾,不予采信)。

### 11.4 根因:瓶颈是独立 run 数,不是想法

各方向反推 80% 功效所需 run:

| 分析 | 效应 | 当前 test run | 需要 | 倍数 |
|---|---|---|---|---|
| L1 flip 集 | 0.547 | 23 | 276 | 12× |
| 自报分判错 | 0.559 | 27→35 | 94 | ~3× |
| 修复价值 | 0.553 | 29 | 410 | 14× |

**语料 515 run;最难者需约 2,000。** 学长实测 29 run/天 → 约 50 有效采集日。
**D&B(9 个月)来得及,ARR(3-4 个月)来不及。**
修正:完整 held-out 侧只产出 35 个可用 run(此前估约 102),缺口比想象更大。

### 11.5 结论

七次尝试全部死于同一处:效应≈0.55,run 聚类后不可分辨。这不是建模失败,是样本量事实,
且可证伪:**同样实验在 4 倍 run 上重做,真而小则解析出来、零则显示为零,两种结果都可发表。**
采集口径应改为**冲 run 数**(多 seed 浅树 > 少 seed 深树),学长新协议方向正确。
