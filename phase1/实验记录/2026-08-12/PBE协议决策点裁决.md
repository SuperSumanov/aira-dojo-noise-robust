# 2026-08-12(夜):arXiv:2601.05930 协议在真实决策点上的裁决

## 背景

zjunlp《Can We Predict Before Executing Machine Learning Agents?》(2026-01,FOREAGENT 系)
发布 18,438 个扁平成对比较(AIDE+AutoMind 于 MLE-bench),主张:LLM 配数据分析报告
可在**不执行任何代码**的前提下以 61.5% 准确率预测哪个方案更好,"比执行基线快 6× 好 6%"。
其评测在**全局采样的对**上进行 —— 正是本项目已证明会被 gap 分布抬高的量
(我们自己的全局 0.828 → 决策点 0.548)。

## 协议忠实度

判官 prompt 逐句取自其 repo `grade/util/prompt.py`:同一系统提示(禁止假设真值/禁止
执行/只输出 JSON)、同一指令句("Predict which solution will perform best WITHOUT
running code")、同一输出格式(`predicted_best_index`)、非 COT 变体。两臂:
`desc`(仅任务描述)与 `desc_report`(+ 数据分析报告)。**唯一偏离**:我们的报告由
qwen-max 从赛题 description.md 生成,未做其"执行验证"步 —— 若 priming 无信号则偏离
无关紧要(desc 臂无此偏离且同样塌);判官用 qwen-max(此前测得一致性最高 0.79)而非
其 DeepSeek-V3.2/GPT-5.1;代码截断 6000 字符。

采样:干净 b0 决策集,150 难 + 150 易,任务分层,seed 7;**每对双序提问**,
报序平均准确率;序间不一致率如实公布。全部 600 对次 × 2 臂解析成功率 100%。

## 判读

1. **执行前预测协议在真实决策点整体塌到掷硬币** —— 不只难区:易区(gap≥1e-2)也是
   0.50/0.48。兄弟代码太相似,全局对上可用的表面启发式(不同 lineage/质量层的对)
   在决策点全部失效。这解释了 61.5%(全局)与 0.48-0.50(决策点)的落差,与本项目
   反转结构(0.828→0.548)完全同构。
2. **报告 priming 非但不救,反而更不稳**:序间不一致 40.0% → 48.3%,准确率 0.500 →
   0.478。"验证版报告能救回来"的反驳不能排除,但方向证据不支持。
3. **同一批对上执行信号 0.73/0.82 显著工作**,噪声上界 0.8962(此集精确)——
   塌缩不是任务不可判,是信号类别的差别。执行悬崖的第三次独立复现
   (静态 critic、RM、LLM judge 三个家族全部)。
4. 对论文:这把"又一个负结果"升格为**对一个活的 2026 正面主张的直接裁决**,
   且有精确噪声计量背书。写作时须注明三点偏离(报告未验证 / 判官型号 / 截断),
   并引用其原始设置以示公平。
