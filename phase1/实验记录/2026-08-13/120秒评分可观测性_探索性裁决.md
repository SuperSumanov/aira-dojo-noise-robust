# 120 秒评分可观测性：探索性裁决（2026-08-13）

## 裁决

**BORDERLINE。** 现有任务内的 artifact-score 可观测性很容易预测，但主要增益不能区别于 task prior，
且 whole-task 迁移不稳定。因此不进入通用 propensity selector；旧 100-set 数据对方法开发继续关闭。

## 冻结结果

- 数据：230 cards / 52 physical runs / 19 tasks；120 秒 finite pristine score 为 86/230；93 份代码按
  预注册截断到前 20,000 字符。
- 主 `code_task_tfidf`：AUC 0.8628876，AP 0.8153983，Brier 0.1524735，log loss 0.4721441。
- run-cluster AUC CI：[0.7601925, 0.9482508]；task-cluster AUC CI：[0.6951298, 0.9605566]。
- 五个 split seeds 的 AUC：0.8629 / 0.8444 / 0.8572 / 0.8596 / 0.8514；median 0.8571544，
  sample variance 0.0000532545，minimum 0.8443960。
- task-only：AUC 0.8642200、Brier 0.1596470。主模型 AUC 相对 task-only 为 -0.0013324；Brier gain
  为 +0.0071735，但 run/task CI 分别 [-0.0045498,+0.0164912] / [-0.0058355,+0.0175994]，均跨 0。
- run-level Brier gain sign：37 positive / 15 negative / 0 ties，双侧 p=0.003185。它说明多数 run 有
  小幅改善；与幅度 CI 跨 0 不矛盾，不能用 sign 结果覆盖预注册的校准幅度门。
- code-only：AUC 0.8355943；但代码包含任务 schema/path，不能据此断言跨任务通用规律。
- whole-task LOTO：pooled AUC 0.6676357，task-bootstrap CI [0.4553845,0.8388149]；8 个含两类标签
  任务的 macro AUC=0.6113828，其中任务间从 0.0714 到 1.0000，迁移异质性很大。
- 控制：label oracle AUC=1.0；固定 CRC32 控制 AUC=0.5770（仅代码路径控制，不参与裁决）。
- 不导入主脚本的 verifier 复算标签、SHA、fold/run 隔离、逐模型点估计、五 seeds、per-run Brier、
  controls 与裁决，全部通过。

## 预注册门逐项

通过：主 AUC≥0.65、run/task AUC CI 下界>0.5、run sign p<0.05 且方向为正、五 seeds median/min、
完整性与控制。

未通过：

1. Brier gain 的 run/task cluster CI 下界均未严格大于 0；
2. LOTO task-cluster CI 下界 0.4554 未严格大于 0.5。

故按预注册为 **BORDERLINE**，不是 GO-FEASIBLE。

## 科学解释边界

最可信的解释是任务/数据管线决定了很大一部分 120 秒可观测性。task-only AUC 已达 0.8642，加入代码
没有提升排序；代码使平均 Brier 略好且多数 run 方向为正，但效应幅度不稳。因而这不是“我们已经能从
代码预测执行成功”的正结果，更不能据此进行跨任务 pruning。

它仍给方法设计一个明确边界：若新数据上开发删失模型，应该 task-conditional；对未见任务必须
abstain，不能把 pooled AUC 当迁移保证。下一步先用 passive watcher 记录连续执行的 time-to-artifact
与稳定 snapshot，检验事件时间是否比单一 120 秒二值标签提供更可迁移的结构；若仍不稳定，转向独立的
schema-first operator 干预。
