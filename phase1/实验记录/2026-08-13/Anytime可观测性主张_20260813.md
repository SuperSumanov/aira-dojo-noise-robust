# 主张收敛：Anytime MLE Search 的可观测性干预

日期：2026-08-13
状态：**方法假设与后续实验规范，不是已经成立的效果结论**

## 1. 一句话主张

自由形态 MLE agent 的瓶颈不只是“最终执行很贵”，而是候选的质量反馈在早期具有**选择性不可观测性**：
一些候选很早产生可由外部 pristine grader 评分的 artifact，另一些候选在相同预算内完全 silent。执行前 critic
在真实 sibling 决策点接近随机；只在已有 artifact 的候选上排序又会产生选择偏差。因此，候选 operator 本身应被改造成
anytime algorithm：先产生候选特异、可验证且不可变的 cheap probe，再在同一进程中继续完整训练。

若因果实验成立，论文方法不是“又一个 early metric predictor”，而是：

1. 为开放式 MLE 程序定义可执行的 anytime artifact contract；
2. 用 host monotonic time、内容哈希与外部 pristine grading 建立不可伪造的轨迹；
3. 在相同生成、执行和评分预算下，用 probe-first operator 降低赢家不可观测损失，并改善固定预算搜索结果。

## 2. 精确问题定义与 regret 分解

先把所有任务指标定向为“越大越好”。候选集合为 `S`，最终真实分数为 `Y_i`。在时刻 `tau`，已产生合法、候选特异
artifact 的集合为 `O_tau`，其 probe 分数为 `P_i(tau)`。定义：

- `i* = argmax_{i in S} Y_i`：最终赢家；
- `i*_O = argmax_{i in O_tau} Y_i`：当时可观测候选中的真实最优者；
- `ihat = argmax_{i in O_tau} P_i(tau)`：probe selector 的选择。

只要 `O_tau` 非空，总选择 regret 有如下逐集合恒等分解：

`Y_i* - Y_ihat = (Y_i* - Y_i*_O) + (Y_i*_O - Y_ihat)`。

第一项是 **observability loss**：最终赢家或更强候选尚不可评分；第二项是 **ranking loss**：在已经可评分的候选中
probe 排错。两项必须分别报告。若 `O_tau` 为空，策略必须显式 abstain/继续执行，不能用共同 sample submission 冒充候选信号。

这个分解避免三个旧错误：

- 只在 observed 子集上报高 accuracy，掩盖 silent 候选；
- 把 artifact 是否出现直接当作质量；
- 用一个 headline accuracy 混合覆盖率与排序能力。

## 3. 当前证据只支持到哪里

- 干净真实 sibling 决策点上，执行前静态 predictor、LLM judge 和外部 pairwise 方法没有形成稳定正结果；不能再靠换大模型
  宣称突破。
- 旧的 100 sibling-set / 230-card fidelity 集显示，120 秒已有的外部 submission score 在可决定集合上有排序价值，
  但 missingness 很强且具有选择性；该集合来自冻结 b0 test，只能作锁定描述和上界，绝不能用于训练或继续调阈值。
- continuous watcher 已验证时间轨迹采集基础设施可用；late-artifact pilot 的 6 个 silent 候选到 600 秒仍无 finite artifact，
  因而旧数据上的被动等待路线已关闭。
- schema/probe smoke 只检验 contract 可行性；即使 PASS，也不代表最终质量或搜索收益提高。

## 4. 方法边界：已有工作已经覆盖什么

- KompeteAI 已用 reduced-epoch logs、候选描述、anchor 和 shared reference architecture 预测完整分数，并报告加速；
  因此不能声称首次用 early metrics 或首次加速 MLE pipeline evaluation。
- delayed-feedback best-arm identification 已研究偏置/无偏 partial feedback；missing/delayed feedback 本身不是新概念。
- failure-aware Bayesian optimization 已研究仅成功时可观察 objective；加一个 failure classifier 也不构成 novelty。
- EET 已做 agent early termination；“会早停”本身不是 novelty。
- SandMLE 已用微型合成环境降低 MLE execution latency，并把合法输出作为 milestone reward；不能声称首次关注 valid artifact。

我们必须用实验建立的差异是：真实自由形态 MLE-agent 候选、真实 sibling 决策、候选特异且可外部评分的 immutable
artifact contract、host 轨迹与 run/task-aware 推断，以及它对固定预算搜索而非单次 pipeline 运行的因果影响。底座 LLM 不微调。

## 5. 方法最小实现：Probe-First Search

每个候选程序必须按顺序完成：

1. 用当前候选真实的特征、标签和模型族训练 cheap probe；
2. 原子写入不可变 `candidate_probe.csv`，按同一字节提升为 `submission.csv`，打印哈希 marker；
3. 在同一进程中继续完整候选；成功后再原子替换 `submission.csv`，但永不修改 probe；
4. host watcher 独立记录首次稳定时间、内容哈希、每次 transition 和固定 checkpoint；
5. 候选退出后才调用 pristine grader，候选进程看不到隐藏标签或 grader。

第一版 selector 不训练复杂模型：对已有 probe 用外部分数排序，对 silent 候选 abstain/保留。只有 coverage 与 fidelity
在新 discovery runs 上成立后，才开发 censored/risk-controlled controller。

## 6. 因果实验必须回答的四项

在机制冻结后的新任务、新 seed 和新 physical runs 上，比较 original operator 与 probe-first operator；两臂固定底座、提示中
除 contract 外的内容、算子集、conditional debug 预算、API/GPU 预算和外部 grader。每个 operator 生成一次，之后离线复用
同一候选轨迹比较 selector，不重复支付生成成本。

逐 task×seed 报告：

1. `Pr(T_i <= 120s)` 与 time-to-first-valid-artifact；
2. 最终赢家在 120 秒的可观测率和 observability loss；
3. observed 集内部的 ranking loss / top-1；
4. 固定总 GPU 时间下的 best final score、总 regret、grader 次数、wall time 与最终质量非劣性。

推断以 task-clustered 和 run-clustered paired bootstrap 为主；不能只报 card-level binomial CI。任务失败、无 artifact、grader
失败和 abstention 全部进入分母。

## 7. 资格门与停止规则

- feasibility smoke：两个预冻结任务都须在 host 120 秒内产生合格 probe，且至少一个出现合格 full transition；否则 FAIL。
- 若第一次草稿因通用 runtime/API 错误失败，只允许在**另立预注册、新任务和新 seed**下测试一次固定 conditional-debug
  operator；不得修补已知代码后回填原 smoke。
- conditional-debug gate 再失败，则 prompt-only schema route 关闭；下一候选只能是 runtime-owned probe API，不能继续改 prompt。
- 只有 feasibility PASS 才能做独立 A/B；A/B 只有在 coverage 上升且 final quality 非劣时才能扩规模。
- 任何单任务主导、run-level 推断不通过、隐藏 grader 开销被省略、或旧 frozen test 被用于训练/调参，均立即降格。
