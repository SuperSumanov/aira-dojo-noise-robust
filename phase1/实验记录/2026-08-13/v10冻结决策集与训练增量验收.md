`phase1/build_decision_v10.py` 打印并经第二次独立重跑逐文件 `diff` 验证。

| budget | 训练（旧有效 + 新） | 冻结测试（有效 / 隔离） | 新 run 扩展测试 |

硬性验收结果：

- v10：15,158 cards；15,140 有限标签；18 张隔离；624 个物理 run。
- 原冻结宇宙：586 runs / 134 held；新增 38 runs，按同一 seed=7 规则产生 11 个新 held run。
- b0/b1/b2 的每一个旧有效冻结 pair 均被 v10 构建器同方向复现：missing=0、extra=0、reversed=0。
- 冻结测试节点进入 v10 训练：0；训练 run 与扩展测试 run 交集：0；跨物理 run 的 sibling set：0。
- 9 个 JSONL 均由 `allow_nan=False` 写出；严格凭据形态 0、重复有序 pair 0、反向冲突 0。
- 两次完整构建的 11 个文件逐字节一致（`diff -rq` 无差异）。

## 发现并修正的历史问题

旧 `decision_clean_b0.jsonl` 实含 1,499 行，而不是干净的 1,498 行。其中一行引用
v9 的非有限标签，且 `gap_raw=NaN`。它不能进入严格 JSON 数据发布，也不能参加评测。
新产物只在 `decision_frozen_v10_b0.jsonl` 中隔离这 1 行；其余 1,498 行逐对不变。

旧 README 所写 b0 训练侧“3,777”也是过期数字。远端真实
`decision_pairs_runsplit.jsonl` 有 3,908 条 b0 train，其中 1 条引用非有限标签；有效
旧训练对恰为 3,907。v10 重新构建得到的旧有效部分与这 3,907 条逐对完全一致。

## 文件角色（不得混用）

- `decision_train_v10_bK.jsonl`：仅供训练。绝不含 held run。
- `decision_frozen_v10_bK.jsonl`：论文 headline 冻结测试；不得进训练。
- `decision_extension_v10_bK.jsonl`：仅含 v10 新 held run，作为扩展/前瞻测试单独报告；
  不得与 headline 混算，也不得进训练。
- `runsplit_holdruns_v10.json`：完整的旧/新增 run 分配证据。
- `decision_v10_audit.json`：输入 SHA、计数和全部验收断言。
