# 任务条件风险证书早停：零 GPU 预注册

时间：2026-08-13（读取本策略结果之前）

## 1. 问题

120 秒 coverage-aware escalation 在冻结 100 个 sibling sets 上有 0.9600 eventual
endpoint identity；实际部署 mixed 输出达到或超过 all-full 的比例为 0.9200。因
144/230 candidates 沉默，restart/full 成本仍为 0.9850。静态 critic 和早期 trace 排序器
都不能可靠地在 silent candidates 中选优。这里不再预测它们的相对顺序，而问一个更保守的
问题：**当已有 artifact 的外部分已经高到超过训练侧该任务“整次 run 最优值”的有限样本
上界时，能否带风险证书地接受 incumbent、跳过该组 silent candidates？**

## 2. 冻结边界

- 测试总体仍为 `fidelity_manifest.jsonl` 的 100 sets / 230 children / 52 physical runs；
  120 秒结果、精确 runtime、任务方向均冻结。
- 校准数据仅来自 v10 `hold` 之外的物理 runs；所有测试 manifest runs 必须属于 `hold`，
  否则 fail closed。测试节点及测试 run 绝不进入校准。
- 每个校准单元是一个物理 run。对任务 `t`，先取该训练 run 内所有 finite card 的有向
  utility 最大值，得到交换性校准样本 `M_t`。这比用逐 card 分位数更保守，并同时覆盖同一
  test run 中多个 parent decisions。

## 3. 固定证书

对风险水平 `alpha`，阈值为训练 run maxima 的有限样本单侧 conformal quantile：

`k = ceil((n_t + 1) * (1-alpha))`。

若 `k > n_t`，阈值设为 `+inf`，该任务永不提前接受；否则取第 `k` 小的 run maximum。
在任务内新 run 与校准 runs 可交换这一假设下，新 run maximum 超过阈值的边际概率不大于
`alpha`。这不是无条件分布保证；协议漂移、run 大小差异和任务内非交换性都必须作为限制。

- 主风险水平预先固定为 `alpha=0.10`。
- 同时完整报告 `0.05` 和 `0.20` 的风险-成本曲线，不能事后用它们替代主结果。
- 无拟合、无阈值调参、无读取测试标签后改规则。

## 4. 策略与成本

每组运行全部 candidates 120 秒：

1. 若无可评分 artifact，完整升级所有 candidates；
2. 若最佳 artifact 的有向外部分 `>=` 该任务阈值，立即接受 artifact incumbent，不升级
   silent candidates；
3. 否则完整升级全部 silent candidates，并在共同外部分尺度上选择。

对照为 all-escalate、artifact-only 和 full-external。成本使用逐 candidate 历史精确 runtime，
同时报告 restart 与 resumable continuation。主质量量为实际部署的有向 mixed score：
artifact 候选使用停止时 `sub_score`，升级候选使用 full `graded`；与 all-full 最优分比较并
报告 (i) `deployed_matches_or_beats_full` 二元量、(ii) raw directed score difference。
eventual endpoint identity 只作 routing diagnostic。质量推断以 physical run 聚类 bootstrap
10,000 次、seed=7。

## 5. 预注册裁决

主比较是 `conformal_a10 - all_escalate` 的 `deployed_matches_or_beats_full` 配对差；同时
必须完整报告 raw directed score difference，防止二元阈值掩盖少数大损失。

- **GO**：run-cluster 95% CI 下界 `>= -0.05`（5pp 非劣界），且 absolute
  `restart/full <= 0.90`；可称为“在交换性假设下的风险控制早停候选”，仍需前瞻复现。
- **BORDERLINE**：部署成功率点估计无下降且 restart/full `< 0.95`，但未同时达到 GO；
  只能扩样验证。
- **KILL**：其余情况，或任何 split/覆盖/方向断言失败。

不能把 oracle、`alpha=0.20` 或测试后挑出的分位数用于 headline。

## 6. 可复现要求

纯 CPU、无 API/GPU。记录全部输入 SHA256、脚本 SHA256、commit、命令、seed、逐任务校准量、
逐 parent 决策、run-cluster CI；同命令两次输出必须逐字节一致。

## 7. 冻结后结果（不得用于改写以上规则）

13 项 pre-flight 全部通过：v10 为 15,158 cards / 624 runs，其中 15,140 finite；冻结测试为
100 sets / 230 children / 52 physical runs / 19 tasks，52 个测试 run 全部属于 145 个 hold
runs。校准与测试的 pair/node/raw-code-hash 交集均为 0，prior hold 134/134 保留。

| policy | 有效早停 | deployed ≥ all-full | 相对 all-escalate 配对差（run-cluster CI） | restart/full | continuation/full |
|---|---:|---:|---:|---:|---:|
| all-escalate | 0 | 0.9200 | 0.0000 [0.0000, 0.0000] | 0.9850 | 0.9312 |
| conformal α=0.05 | 0 | 0.9200 | 0.0000 [0.0000, 0.0000] | 0.9850 | 0.9312 |
| **conformal α=0.10（主）** | **0** | **0.9200** | **0.0000 [0.0000, 0.0000]** | **0.9850** | **0.9312** |
| conformal α=0.20 | 0 | 0.9200 | 0.0000 [0.0000, 0.0000] | 0.9850 | 0.9312 |
| full-external 正控 | 0 | 1.0000 | +0.0800 [+0.0202, +0.1538] | 1.0000 | 1.0000 |

主策略的非劣下界虽然为 0，但完全没有触发有效早停，restart/full=0.984978 明显未达到
0.90，故严格按预注册判为 **KILL**。α=0.05/0.10/0.20 都没有在“存在 silent candidate”
的集合上超过任务内训练 run-max 阈值；绝对分数风险证书退化为 all-escalate，不构成方法突破。

正式运行前的 smoke 曾把 α=0.20 在一个 `n_silent=0` 集合上的阈值通过计成 1 次“早停”；
逐行审计后把计数定义修正为必须实际跳过至少一个 silent candidate。该修正不改变任何选择、
成本、质量或裁决；修正后两次正式运行的 summary/per-set/calibration/stdout 均逐字节一致。
