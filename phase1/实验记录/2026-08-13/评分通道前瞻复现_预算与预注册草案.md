## 功效与预算

发现集有 52 个 physical runs，其中 5 个 run 的严格共同覆盖比较出现非零差异，经验
informative-run rate=`5/52=0.0962`。用 `r=0.10` 近似，令 informative run 中有利方向率
为 `q`，对双侧 α=0.05 exact sign test 做无 optional-stopping 的精确功效计算：

| 新 runs | q=0.90 | q=0.80 |
|---:|---:|---:|
| 90 | 0.599 | 0.313 |
| 120 | 0.779 | 0.454 |
| **150（固定推荐）** | **0.884** | **0.578** |
| 240 | 0.987 | 0.817 |

150 runs × 最多 2 sets/run × 当前均值约 2.3 children/set ≈ **690 个 120 秒 replay**。
理论 cap 上界为 **23.0 GPU·h**；按 10533 的实测提前完成比例，预计 **17–23 GPU·h**。
4×1-GPU 并行预计 **4.3–5.8 小时墙钟**，不含排队。无 LLM API 消耗，不训练/微调模型。

240-run 保守方案需约 1,104 replay、27–36.8 GPU·h；当前不推荐。固定 150 后无论结果如何
都不在原假设上追加到 240，避免可选停止。
