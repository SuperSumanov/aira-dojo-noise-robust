`QUALITY_KILL`。因此不能继续调 prompt，也不能把 typed artifact/validator 的宽泛想法直接包装成新颖方法。

旧 first-960 预注册要求至少 1,500 structural pairs；当前仍差 284。因此不得因已经超过 150 runs 或想尽快得到
正结果而提前开 label vault。新 archive 可继续 append-only 收集；达到门后才冻结时间 cohort 并一次性评估。

## 2. 防 scoop 结论

近期工作已经覆盖宽泛的“validator/harness 帮 agent 修复”主张：

- [VeriHarness](https://arxiv.org/abs/2607.14167) 比较结构化 validator feedback 的 repair loop；
- [HarnessFix](https://arxiv.org/abs/2606.06324) 从失败轨迹定位并修复 harness flaw；
- [TAG](https://arxiv.org/abs/2607.02615) 明确提出 test-driven artifact generation 与 deterministic schema tests；
- [Tool Forge](https://arxiv.org/abs/2605.28000) 把工具做成携带验证证据的受治理 artifact。

所以“加 schema validator / structured feedback / 自动修 harness”不能作为我们的 headline novelty。若未来实现 typed
submission adapter，它只能是 benchmark baseline 或受限系统组件；必须证明它是 prediction-preserving 的通用
serialization contract，并在真实 sibling fixed-budget search 上有因果收益，才可能成为方法贡献。

对 MLE-agent 搜索数据，当前检索到的直接邻居仍是 MLE-bench、AIRA-dojo、MLEvolve 与 Gome；它们评估 agent 或
提出搜索框架，但没有发现公开的 **run-clean physical search trees + true sibling decision graph + source-retention/
censoring contract + noise/query-cost accounting + temporal holdout** 数据集。因此最可守的正面路线是 D&B benchmark，
而不是继续追逐一个已被相邻工作覆盖且本地 A/B 失败的 prompt/harness 技巧。

## 3. 下一步（不提前读 outcome）

1. 保持 6 小时 credential-safe intake monitor；新归档只形成不可变 transaction。
2. 1,500-pair 门通过前只做结构支持与版本化 corpus 工程；不运行旧 first-960 scorer。
3. 门通过后，把冻结 predictor 的**时间外推**作为 headline benchmark：真实 sibling、cross-run uniform 与 gap-transport
   三图；run/task clustered CI；完整 coverage、missingness 与 query/init cost；不把全局 pairing accuracy冒充搜索效用。
4. typed artifact adapter 只保留为 future baseline，先做 prediction-preserving repairability 上界；没有足够可无损修复
   的支持就不申请 GPU/API A/B。
