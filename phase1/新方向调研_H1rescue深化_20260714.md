# 新方向调研（H1 + rescue 之上）——lean deep-research 综合

日期：2026-07-14 ｜ 5 条精准 WebSearch（未抓全文，省 token）。承接 [[advisor-feedback-h1-rescue]] / [[h1-representation-probing-result]]。

> 目标：在 H1（表征探测）+ rescue（失效检测）地基上找新思路。结论：方向都活着，但 landscape 比想的拥挤——**锐化**可辩护角度。

## 逐方向 novelty 判读 + 最接近前作

**A1 低维"质量方向"——支持强、部分被占**
- **The Confidence Manifold `arXiv:2602.08159`**：跨 9 模型 5 家族，correctness 表征活在 **3–8 维**、线性胜非线性；**"内部信号强 AUC 0.80–0.97、输出弱 0.44–0.64"**——**神呼应我们 H1**（冻结内部 probe 打败自报分=内部>>输出）。
- distinct 角度：我们做**连续 TASK grade（非二元正确性）+ 自报分/长度独立**。必引它划界。

**A3 因果 steering——最 novel、最赌**
- **Steering Code LLMs `arXiv:2603.23629`**：steering code 模型只控**语言/库**、不控质量。→ "steer 解质量方向 + 测对 grade/自评分的**因果**效应"是空白。赌在质量概念太 subtle、未必有干净因果效应。

**B1 reward-hacking / 验证过拟合检测——最热、最该做**
- **`arXiv:2601.20103`** reward-hack 检测 benchmark（code）；**`arXiv:2604.01476`** 用**表征级信号**抓 reward hacking；**`arXiv:2606.07379`** capped-eval 抓作弊；SOTA(GPT-5.2) 只抓 63% → 难、有空间。
- distinct 角度：**从冻结 code-LLM 检测 MLE 的"验证过拟合（自报 CV 虚高）"、不执行、独立于自报分**——把 rescue 升级成切安全热点的检测贡献。必引上面几篇划界。

**C1 跨模型——大部分被占、最弱**
- `2602.08159` + `2511.16699`：**编码普遍、但方向不跨模型 transfer（r=−0.06~0.18）**。→ "同一 probe 跨模型迁移"别声称；"每个模型里都可解码（编码普遍、基向量模型特有）"成立但已知。降为脚注。

## 推荐排序
1. **B1 reward-hacking/过拟合检测 = 最强新方向**（热点+rescue 已有机制+有用+可辩护）。
2. **A1 低维质量方向 = 最便宜的 H1 深化**（测连续 grade 是否也 3–8 维，焊死"内部>>输出"）。
3. A3 因果 steering = 高风险高回报。
4. C1 跨模型 = 脚注。
