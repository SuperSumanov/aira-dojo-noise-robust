# CUHK CSE 服务器配置 — 操作记录

记录从零配置 linux5 GPU 环境的完整过程、遇到的坑和解法。配套文件在同目录：
`ssh_config`、`env_setup.sh`、`run_experiment.sbatch`、`CUHK_CSE_GPU_上手文档.md`。

## 账号与资源

- 项目侧账号：`yzyang4`（linux5）；老网关 proj103 上是 `yzyang`
- 大存储：`/research/d7/spc/yzyang4`（1TB，到期 2026-09-29）
- 跑实验主力机：`linux5.cse.cuhk.edu.hk`（Ubuntu 24.04）
- 校园代理：`http://proxy.cse.cuhk.edu.hk:8000/`（出外网必须走它）
- SLURM 配置：`/opt1/slurm/gpu-slurm.conf`（靠 `SLURM_CONF` 指定）

## 连接方式（重要）

linux5 **只能 CSE VPN 直连**：
- 先连 CSE VPN，再 `ssh linux5`
- 网关 gw 对 linux5 是 `administratively prohibited`，走不通
- 刚连上 VPN 若报 "unknown host / 不知道这样的主机"，是内网 DNS 没热，重试一次即可

本地 `~/.ssh/config` 见 `ssh_config` 文件。

## 踩过的坑与解法

1. **VSCode 连 proj103 报 glibc 不满足** → proj103 是 Debian 9（glibc 2.24），太老。
   改用 linux5（Ubuntu 24.04）后正常。

2. **开 VPN 后连网关 timeout** → VPN 和网关跳转是两扇互斥的门。
   linux5 走 VPN 直连，不要再加 ProxyJump。

3. **VSCode 装 server 失败（Network is unreachable）** → linux5 出外网必须走代理。
   解法：建 `~/.wgetrc` 和 `~/.curlrc` 写入代理；VSCode 设置加
   `"remote.SSH.useCurlAndWgetConfigurationFiles": true` 和 `"remote.SSH.localServerDownload": "off"`。

4. **登录默认 shell 是 tcsh** → bash 生态更顺，操作前先 `bash`。
   env_setup.sh 是 bash 语法，sbatch 用 `#!/bin/bash`，srun 用 `--pty /bin/bash`。

5. **`ulimit -u 65536` 报 Operation not permitted** → 非 root 无权提升进程数上限，无害。
   已改为 `2>/dev/null || true` 静默跳过。

6. **`sinfo` 报找不到 /etc/slurm/slurm.conf** → 正常，靠 `SLURM_CONF` 变量指向 gpu-slurm.conf 即可。

7. **`uv pip install torch` 报 Disk quota exceeded** → uv 缓存默认在家目录（配额小）。
   解法：`export XDG_CACHE_HOME / UV_CACHE_DIR / UV_PYTHON_INSTALL_DIR` 全部指向 `/research`。

## 已验证打通的全链路

笔记本 → CSE VPN → `ssh linux5` → `srun ... --pty /bin/bash` → GPU 节点（如 projgpu33, RTX 3090）
→ `torch.cuda.is_available() == True`。

## 可用 SLURM 队列（公共，配 `--account gpu --qos gpu`）

| 队列 | 时长 | 用途 |
|---|---|---|
| gpu_2h | 2 小时 | 调试 |
| gpu_8h / gpu_24h | 8h / 1天 | 中等任务 |
| gpu_72h | 3 天 | 正式训练（常用）|
| batch_168h | 7 天 | 超长任务 |

带 PI 名字的队列（pheng_gpu 等）是各组私有，一般提交不了；组内队列问导师。

## 日常使用速查

```bash
# 连接
连 CSE VPN → ssh linux5

# 进 bash + 加载环境（.bashrc 已自动 source env_setup.sh）
bash

# 激活 Python 环境
source /research/d7/spc/yzyang4/venvs/exp/bin/activate

# 调试用交互式 GPU
srun -p gpu_2h --qos gpu --account gpu --gres=gpu:1 -c 8 --mem=32G --pty /bin/bash

# 提交后台训练
sbatch run_experiment.sbatch
squeue -u $USER            # 看状态
tail -f logs/<作业号>.out  # 看日志
scancel <作业号>           # 取消

# 装包（在 linux5 上，别占着 GPU 装）
uv pip install <包名>

# 看配额
du -sh /research/d7/spc/yzyang4/*
```
