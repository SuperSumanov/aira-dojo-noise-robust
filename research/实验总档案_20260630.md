# 实验总档案(原理版) — 噪声鲁棒 MLE 搜索 + DetectReplan

> 截至 2026-06-30。重点:**每个实验要验证什么、为什么这样设计能验证它**;过程/运维从略。
> 平台:CUHK CSE 单卡 3090 / DeepSeek(不微调权重)。

## 0. 两个实验,各一句话

- **实验一(噪声鲁棒 MLE 搜索)**:验证「穷算力 + 廉价带噪评估下,把评估做*一致/鲁棒*能否救回搜索质量」。
  → 结论:**评估保真度是杠杆;但改"选择统计量"(方差感知/多评平均)不是杠杆。**
- **实验二(DetectReplan)**:验证「能否把 agent 的适应失败,*分解*成可分别测量的"检测成本"与"重规划成本"」。
  → 结论:**分解塌缩(无法分离);但意外得到干净发现——agent 几乎无法从经验推断规则变化。**

# 实验一:噪声鲁棒 MLE 搜索

## 1.1 要验证什么(问题 + 靶子)
- **靶子**:AIRA-dojo 的负结论——「脏评估下,搜索策略不重要」;AIRA_2 把病根诊断为**评估不一致/噪声**。
- **我们的问题**:在单卡 + 只能用廉价带噪评分的条件下,**把评估做得一致/鲁棒,能否保住"评估一致 → 长程搜索稳定"**?(全程不微调 LLM,只动搜索控制器的评估/选择协议。)
- 拆成两个可证伪的前提,先用最便宜的 T0 裁决,再做 T1 主验证。

## 1.2 T0:两个前提的"生死"验证
> 原理:在**已有的 baseline 搜索日志**上离线复算两个相关性,零额外训练,就能判定两条路值不值得做。

**(a) 扩展线前提——"价值结构可池化吗"**
- 想做的事:在搜索控制器里引入 RL 的价值回传(TD/credit assignment)。
- **验证原理**:TD/自举的本质是把子节点价值**回传**到父节点;它只有在「父节点真值能被其子节点真值预测」时才比朴素 MC 强。所以测 **父→子 外部真值的相关性 R²**:R²≈0 → 子节点说明不了父节点 → TD≈MC → **没东西可池化,这条线当场死**;R²>0 → 有结构,值得做。
- 结果:spaceship R²=0.92 但**被单个杠杆点虚高**(留一法 [0.30,0.97]、稳健 ~0.30);nomad 树太碎、凑不出父子边。→ **判定:无稳健可池化结构,RL 线搁置。**

**(b) 主线前提——"评估真的噪吗"**
- **验证原理**:搜索是按 agent **自报的验证分**来选节点的;若自报分与**外部真分**相关性低,就说明搜索在"按噪声选" —— 这正是 AIRA_2 说的评估不一致,被量化出来。
- 结果:自报↔外部 R² = **spaceship 0.14**(n=71)、**nomad 0.72**(n=6)。→ **判定:评估噪声真实存在、且任务相关**(易灌水的分类噪,诚实的回归不噪)→ 主线成立,进 T1。

## 1.3 T1:核心假设的验证(三臂对照)
- **核心假设**:廉价带噪评估下,**方差感知/一致性的选择协议**能把搜索质量拉回接近"完整评估"。
- **验证原理(关键:如何只隔离"评估协议"这一个变量)**:守**公平契约**——搜索策略(greedy)、算子、底座、每任务预算、任务集、数据划分**全部固定**,**只改"搜索期 fitness 怎么算"**。于是任何结果差异都只能归因于评估/选择协议。三臂:
  - **完整(full)**:全量外部真分评估 → 干净评估的**天花板**(参照);
  - **朴素(naive)**:单次廉价 proxy(10% 子样)→ 穷算力 naive 基线;
  - **一致性(consistency)**:k 次廉价 proxy 取 均值−λ·方差 → 待验证的修法。
  (+ 消融 mean(λ=0):只平均不惩罚方差。)
- **完整性原理(HCE)**:评分由外部 pristine 代码算、agent 拿不到标签;数据切 D_train(训)/D_search(搜索期外部评分,隐藏)/D_val(只定最终解)/D_test(不碰)。**三臂逻辑全在评估层,搜索算法一行未改** → 公平天然成立。
- **测什么**:搜索选中解在 **D_val 的真分**,以及 **regret**(选中解 vs 该搜索树内真值最优解的差)——直接回答"这套评估协议有没有把搜索导向好解"。

## 1.4 结果与含义
| 臂(spaceship,5 seed) | 选中解真分↑ | regret↓ |
|---|---|---|
| **完整 full** | **0.803** | 0.009 |
| 一致性(λ=1) | 0.787 | 0.025 |
| 朴素 naive | 0.784 | 0.030 |
| 平均(λ=0) | 0.780 | 0.032 |

- **① 评估保真度是大杠杆**:full ≫ 一切 10% proxy(真分 +0.02、regret 仅 1/3)。
- **② 选择统计量不是杠杆**:朴素/平均/方差惩罚三者真分无差异(0.78–0.787,都在噪声带内)。机制上方差惩罚确实改变了"选谁"(proxy 乐观度 gap 从 +0.077→−0.007),但**不转化为更好的解**。
- **含义**:给 AIRA「搜索策略不重要」补了一个**关键例外——评估保真度**:不是怎么*选*重要,而是评估本身*准不准*重要。卖点应从"方差感知选择"转向**多保真 + 评估预算分配(BAI)**(把廉价评估的有效保真度推近 full)。

# 实验二:DetectReplan

## 2.1 要验证什么
- **现象**:agent 在 episode 中途规则一变就适应失败。**但失败可能有两种来源**:(1) 没**检测**到环境变了;(2) 检测到了却**重规划**不出来。
- **要验证**:能否把这两种成本**分别、定量地测出来**(而不是只看一个笼统的"适应失败率")。

## 2.2 核心原理:为什么"权重冻结 + 2×2 受控信息"能分离检测与重规划
- **关键洞察(论文头条)**:权重冻结的 in-context agent = prompt 的**确定性函数**。prompt 一固定,它的"反应"就固定。于是我们可以**用 prompt 注入信息来外科式地移除某一种负担**:
  - 告诉它「环境变了」→ 移除**检测**负担;
  - 告诉它「新规则具体是什么」→ 移除**推断规则/重规划前置**负担。
- **2×2 受控条件** = {告诉变了:是/否} × {告诉新规则:是/否}:
  - 四格的 regret 差,通过**因子分析**拆出:**主效应(检测信号)= 检测成本**、**告知全部那格仍剩的 regret = 重规划成本**、**交互项小 = 这个分解是有效的(检测与重规划近似独立)**。
- 这就是"按构造可分离识别":不是事后统计推断,而是**设计上**让两种成本各自对应一个可操作的条件。

## 2.3 精确 regret 原理
- 在一个**确定性网格 MDP**里做(导航到目标,中途某步把规则改掉,如"上/下效果互换")。
- **为什么用值迭代**:确定性 MDP 上最优值 V\* 可**精确**算出 → regret = 最优累积回报 − agent 累积回报,**无偏、不靠噪声估计**;且 post-change 段从 agent 实际所处状态单独算。
- 检测延迟用动作序列的 change-point(连续 k 步走"新最优")度量,并用 no-change 对照减掉"碰巧走对"的基线 —— 避免把探索误判成检测。
- 先验 **floor**:可用推理模型在 stationary 上成功率要够高(否则一切免谈)。结果 **18/18=100% PASS**。

## 2.4 结果与含义
| post-change regret(越低越好) | 告诉规则=是 | 告诉规则=否 |
|---|---|---|
| 告诉"变了"=是 | **0.0** | ~16–20 |
| 告诉"变了"=否 | **0.0** | ~15–23 |
(8×8 与 12×12 两次复现,趋势一致)

- **塌缩(分解 NO-GO)**:① 一给规则,regret 立刻=0 → **重规划成本≈0**(干净网格导航,强推理模型给了规则就秒重算);② 只告诉"变了"几乎不降 regret(在噪声带内)→ **检测信号本身没用**。两种成本无法分离,整件事退化成单一轴「你知不知道新规则」。
- **但得到一个干净的重构发现**:**LLM agent 几乎无法从经验自己推断出规则变化** —— 即使把网格放大、后段拉长给它更多步(12×12),不告诉规则它就崩;**只有直接告知具体规则才能适应**。→ 真正的瓶颈是**检测/推断规则**,不是重规划。
